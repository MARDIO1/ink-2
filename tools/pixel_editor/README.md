# Ink Attack 逻辑像素拼装台

双击 `launch_pixel_editor.cmd`，或直接打开 `index.html`。

## 两种素材入口

1. **导入图片**：第一张图片成为核心参考图；后续普通图片按参考图短边的逻辑像素密度重新采样。
2. **打开 MONO PIXEL**：在内嵌窗口中把普通图片像素化，或使用画笔、橡皮、取色、替换、框删、对称和扩展画布等工具逐格修改。

MONO PIXEL 编辑完成后，点击右上角 **导入拼装台**。页面会直接传递透明 PNG、逻辑宽度和逻辑高度，不生成中间下载文件。

使用“框删”工具拖动时，选区旁会实时显示 `宽 × 高 PX`。底部状态栏同时显示逻辑选区尺寸与按 16× 导出后的实际 PNG 尺寸；松开鼠标删除后仍保留最近一次测量值。

## 直导规则

- MONO PIXEL 每个逻辑格内部以 16×16 真实像素传递。
- 拼装台按随图传来的逻辑宽高还原，因此不会把 16 倍输出误当成新的逻辑尺寸。
- 直导部件默认关闭“自动按核心参考图”以保留手工编辑网格。
- 若希望重新匹配核心参考图，选中部件后在右侧开启“自动按核心参考图的逻辑密度重新像素化”。
- 直导后可立即拖动、缩放、拼接和导出。

## 自动缓存

拼装台会在浏览器本地自动保存素材图片、参考图关系、位置、缩放、可见性、黑白/透明设置、画布尺寸、查看倍率和导出规格。关闭并重新打开同一路径的 `index.html` 后会自动恢复。点击“清空”会同时清除本地记录。默认使用适合图片的 IndexedDB；浏览器禁用 IndexedDB 时自动切换到本地存储兼容模式。

## 从拼装台进入 MONO PIXEL

选中任意部件后点击右侧 **在 MONO PIXEL 中编辑**。拼装台会把当前规范化、缩放后的逻辑像素直接送进编辑器。完成后点击 MONO PIXEL 的 **导入拼装台**，结果会回写原部件并保持其 X/Y 拼装位置，不产生重复素材。

## 通用颜色规范

拼装台与 MONO PIXEL 共用四阶灰度：黑色 `0`、深灰 `85`、浅灰 `170`、白色 `255`。新导入图片和 MONO 往返部件默认使用“MONO 四阶”，不会再丢掉编辑器中的两种灰色。检查器仍可切换为纯黑白二阶或保留原色。

## 批量导出部件

点击顶部 **导出全部部件**，浏览器会询问保存文件夹，然后将素材列表中的所有部件分别导出为规范化透明 PNG。重复名称会自动增加 `_2`、`_3` 等后缀，不会互相覆盖。此功能需要支持文件夹选择接口的新版 Chrome 或 Edge。

导出器会检查文件夹写入权限、避开 Windows 保留文件名并限制文件名长度。云盘或同步目录短暂丢失句柄时会自动重试三次；仍失败时会显示中文原因与已经完成的文件数量。此时重新点击导出并选择一个稳定的本地文件夹即可继续。

## 观察拼装画布

- 鼠标滚轮：上下移动画布视口。
- `Shift + 滚轮`：左右移动画布视口。
- 按住鼠标中键拖动：自由平移画布视口。
- 鼠标左键拖动：移动当前部件，不会与视口平移冲突。

## 本地与隐私

两部分都在浏览器本地运行，不上传图片，也不需要 Godot 或服务器。
