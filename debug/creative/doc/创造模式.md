# 创造模式（地图编辑模式）

F2 进出。进去后就是地图编辑器：飞行、画、放钉子、扩大画布、固化并保存场景。

## 操作

| 键 | 作用 |
|---|---|
| `F2` | 进出创造模式 |
| `WASD` | 上帝位移（直接改位置，不走惯性），`Shift` 加速 |
| `1` / `2` / `3` / `4` | 手 / 画笔 / 橡皮擦 / 钉子 |
| `F5` | 固化画布 → 自动把完整关卡保存成 `.tscn` 场景 |
| `Esc` | 照常开菜单 |

屏幕左侧工具栏不会随相机移动或缩放。界面不显示方向按钮；需要扩大画布时使用
`Ctrl + ←/↑/↓/→`，每次默认增加 256 个逻辑像素。已有像素和钉子都会保留，
向左/向上扩大时旧内容的世界位置不变。
`人`按钮用于显示/隐藏小人：进入地图编辑器默认隐藏，按钮选中时显示。
`钉`按钮用于显示/隐藏钉子外观：按钮未选中时，画布标记和已生成实体上的钉子都会隐藏，
但钉子像素、固定点与物理效果不会被删除。
进入地图编辑器时，血条、墨水瓶填充和墨水余量文字会隐藏；退出后恢复进入前的状态，退出按钮保留。
工具栏会拦截鼠标，点击按钮、滑块或开关不会在背后的画布上落墨或放钉子。

## 进入时改了什么

- 玩家本体 `collision_layer = 0`、`collision_mask = 0`：不在任何层，碰不到任何东西，也碰不到它。
- 玩家本体 `gravity_scale = 0`：不下落。
- 小人视觉默认隐藏，但物理体仍作为编辑器飞行和相机锚点存在；左侧工具栏的 `人`按钮可临时显示。
- `WASD` 每帧直接**设速度**（起步/停止都是瞬时的，没有惯性手感）。手/臂不受影响，抓握照常。
- 退出时把层、掩码、重力恢复；**位置不还原**（停在你飞到的那个点）。
- 小画布 `SmallCanvas` 让位：`visible = false`、`active = false`；（`creative.gd` 的 `canvas_path` 默认 `^"../SmallCanvas"`）
  大地图 `MapCanvas`（2048×1024，铺满全图）出现并接管输入。退出时换回来。
- **画图不花墨水**：两张画布都置 `ink_free = true`。进入时会先把画布已经欠的账结清
  （把当时的 `ink_px` 还回瓶子），之后画 / 擦 / 重绘都不再动瓶子 ——
  所以"重绘"不会凭空生墨，地图编辑也不会画到没墨。
- **不掉血**：`InkHealth.damage_enabled = false`。目前唯一会让墨水流血的就是画布绘制，
  它已经被上一条挡住；这个闸门是给以后接碰撞伤害留的入口（`InkHealth.damage()`）。

`process_physics_priority = 15`：在世界步进(10)之后、相机(20)之前改位置，这样相机当帧就跟上。

### 为什么是"设速度"而不是瞬移位置

第一版每帧直接写 `body.position`。本体是手臂两根关节（Hinge + Slider）的锚点，
瞬移等于把锚点一下子拉开，求解器为了追上会把质量只有 2.15 的手臂抽到 **39361 px/s**，
实测 **331 个子步/帧、1074 ms/帧**（`debug_hud` 的看门狗直接抓到现场并退出）。

改成设速度后位移交给物理积分，关节锚点连续，飞行时最大 6 子步、124 FPS（静止 166 FPS）。

## 存图（存整个关卡）

`F5` → `Creative.export_map()`，存的是**整个关卡场景**，不是一个墨水清单：

1. `MapCanvas.generate()` 先把画布上没固化的墨水固化掉，一个像素都不丢。
2. `_sync_node_transforms()` 把每个像素刚体的 PBody 位形**写回它的节点** ——
   节点自己不跟物理走（每帧跟的是视觉精灵），不写回去玩家会被存回出生点。
3. 打包瞬间临时恢复正常游玩布局（玩家显示、`SmallCanvas` 开启、`MapCanvas` 隐藏），避免把编辑器状态写进关卡。
4. `PackedScene.pack(current_scene)` → 写到 `map_path`（默认 `res://map/asset/map.tscn`，固定路径、每次覆盖）。

保存完成后会自动回到原来的编辑状态；无论保存时 `人`按钮是什么状态，保存出的场景都会正常显示玩家。

存出来的东西：`PixelWorld` 根 + `Player` + `Canvas` + `MapCanvas` + 全部墨水物品
（`InkItem` + `PixelShape2D(source=PAINT)` + 内嵌 Image）+ 地面/箱子/HUD/ESC。

**各个地图是平级的关卡**：`main.tscn` 和存出来的 `map.tscn` 结构完全一样，
都能单独打开（编辑器里就能看见，因为根是 `@tool` 的 `PixelWorld`）、也都能当主场景跑。
主菜单里加载哪个是 `ui/menu/src/menu.gd` 的 `GAME_SCENE` 一行的事。

⚠️ 两个前提（都在 `canvas_solid.gd` 里）：运行时固化出来的墨水物品必须**本身就是能存进 .tscn 的形态** ——
形状用 `PixelShape2D(PAINT)` + 内嵌 Image（不是自己造的 `CanvasShape`，它装的是 RefCounted 的
`PixelShape`，`PackedScene` 存不下来）；运行时新建的节点还要补 `owner`，否则 `pack()` 会漏掉它们。

## 载入

`map/src/ink_item.gd` 是墨水物品的脚本（引擎 `PixelBody2D` 的子类）。
它在 `_ready` 的**延迟调用**里按自己的像素补两件事：材质 4 的像素重新打上
`static_anchor_points` 标签，并补上可见的钉子外观。

⚠️ 不能挂在 `_bake_lazily` 上：`PixelWorld.rebuild()` 走的是 `bake_node()` → `bake()`，
不过那个"按需烘焙"的钩子。
