# 组件

6 个可复用场景，只依赖 Theme（不写死颜色）。当前**只有 `ui_resource_preview.tscn` 预览场景在用**；
正式场景（menu/hud/esc/画布工具栏）直接走 Theme 变体，不实例化这些组件。

| 场景 | 结构 | 最小尺寸 | 变体 |
| --- | --- | --- | --- |
| `ink_card.tscn` | PanelContainer + Margin(18) + VBox(8)：标题 + 正文(自动换行) | 360×156 | `CardPanel`、`TitleLabel`、`MutedLabel` |
| `ink_dialog.tscn` | PanelContainer + Margin(24)：标题 + 正文(撑满) + 右下 取消/确认 | 460×240 | `OverlayPanel`、`PrimaryButton`（两个按钮各 110×44） |
| `ink_meter.tscn` | VBox(6)：表头(名称 + 数值) + ProgressBar(高 18) | 280×54 | `AccentLabel`、`MutedLabel`、`InkMeter` |
| `ink_primary_button.tscn` | Button | 160×44 | `PrimaryButton` |
| `ink_secondary_button.tscn` | Button | 160×44 | 无（默认即次要样式） |
| `ink_danger_button.tscn` | Button | 160×44 | `DangerButton` |

`ui_resource_preview.tscn` 是这 6 个组件加 LineEdit / OptionButton 的预览场景，编辑器里 F6 直接跑。

来源与落位约定同 `ui/theme/doc/主题.md`。
