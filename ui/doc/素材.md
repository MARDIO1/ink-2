# 画布素材

工具面板的 8 组图标：`ui/asset/<name>.png` 是源图，`ui/asset/<name>.tres` 是只描述透明包围盒的
`AtlasTexture`（不改写、不二次压缩源图，换图只需替换同名 png）。

| 资源 | 原始文件 | 裁切区域 (x, y, w, h) |
| --- | --- | --- |
| `brush.tres` | 绘图.png | (912, 512, 480, 464) |
| `eraser.tres` | 橡皮.png | (912, 512, 480, 464) |
| `clear.tres` | 清理.png | (912, 512, 480, 464) |
| `fill.tres` | 填充.png | (36, 40, 132, 128) |
| `generate.tres` | 生成实体.png | (28, 40, 132, 128) |
| `return_to_canvas.tres` | 返回画布.png | (912, 512, 480, 464) |
| `nail.tres` | 钉子.png | (36, 40, 132, 128) |
| `canvas_frame.tres` | 画布-transparent.png | (64, 144, 1920, 1344) |

源图来自 `D:\2D Admination\UI`（与已关闭的 PR #2/#3 同源，命名批次不同）。

这些素材按 16×16 源像素块绘制：场景里用最近邻过滤、尽量整数倍显示，避免线宽抖动。
项目**没有**开全局 nearest（`project.godot` 的 `default_texture_filter` 保持默认），靠节点上的
`texture_filter` 单独设。
