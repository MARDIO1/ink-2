# 关卡选择

`ui/level_select/level_select.tscn`：`root` 的**第二屏** —— 主菜单点「开始」之后才挂上，列出所有真关卡，点一个才进游戏。

- **判据（内容判据）**：递归扫 `res://map` 下的 `.tscn`，只收"场景状态里存在名为 `Player` 的节点"的。
  地形件（一块烘好的静态图）没有 Player，自动排除；目录名不参与判断。
- 正式四页（扉页 / 第一页 / 第三页 / Peak）按阅读顺序固定排在前面，其余扫出来的关卡按路径排在后面。
  `map/asset/blank_level.tscn` 是模板，不算关卡，扫描时显式排除。
- 列表项是文件名（去扩展名），鼠标悬停显示完整 `res://` 路径。
- 选中的路径用 `level_chosen(path)` 信号交给 `root/src/root.gd`；`root` 负责换关 + 挂成品 UI。
- 加了新关卡（创造模式 F5 存到 `map/` 下任意位置）**重启即出现在列表里**，这里不用改。

## 新建空白地图

列表**最上方**固定一个「新建空白地图」按钮。按下后把 `map/asset/blank_level.tscn` 复制成
`map/asset/imported/新地图N.tscn`（N 取第一个没被占用的编号），然后直接进入这张新图，
按 `F2` 就能开始编辑。

- 模板只有一块地面和必要的运行时节点（`PixelWorld` / `Player` / `SmallCanvas` / `MapCanvas` /
  `SimulationRuntime` / `Creative` / `debugHUD`），不含任何内容；改模板就等于改所有新地图的起点。
- 复制时会**去掉场景头里的 `uid=`**：两张 `.tscn` 共用一个资源身份会让 Godot 认错场景。
  模板自己也刻意不写 uid。
- 写盘走 `FileAccess`，和创造模式 F5 一样是编辑器内可用、导出成 PCK 后只读。

## 为什么判据不是"目录约定"

`map/` 底下混着两种东西：真关卡（`map/main.tscn`、`map/asset/map.tscn`）和地形件。
按目录分要额外搬文件、改一堆引用；按内容分，创造模式存出来的关卡落在哪都进列表。

## 自测

headless 跑 `res://root/root.tscn`，stdout 会打印一行 `LEVELS: [...]`——那就是扫出来的关卡表。
