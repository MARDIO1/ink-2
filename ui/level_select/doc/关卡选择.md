# 关卡选择

`ui/level_select/level_select.tscn`：`root` 的**第二屏** —— 主菜单点「开始」之后才挂上，列出所有真关卡，点一个才进游戏。

- **判据（内容判据）**：递归扫 `res://map` 下的 `.tscn`，只收"场景状态里存在名为 `Player` 的节点"的。
  地形件（一块烘好的静态图）没有 Player，自动排除；目录名不参与判断。
- 列表项是文件名（去扩展名），鼠标悬停显示完整 `res://` 路径，按路径排序。
- 选中的路径用 `level_chosen(path)` 信号交给 `root/src/root.gd`；`root` 负责换关 + 挂成品 UI。
- 加了新关卡（创造模式 F5 存到 `map/asset/map.tscn`）**重启即出现在列表里**，这里不用改。

## 为什么判据不是"目录约定"

`map/` 底下混着两种东西：真关卡（`map/main.tscn`、`map/asset/map.tscn`）和地形件。
按目录分要额外搬文件、改一堆引用；按内容分，创造模式存出来的关卡落在哪都进列表。

## 自测

headless 跑 `res://root/root.tscn`，stdout 会打印一行 `LEVELS: [...]`——那就是扫出来的关卡表。
