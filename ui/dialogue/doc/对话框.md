# 像素打字机对话框

`dialogue_box.tscn` 是已接入 `ui/game_ui.tscn` 的底部对话框模块。正文使用项目统一的 IPix 中文像素字体链，以 16px 逻辑字号一比一绘制；右下角继续提示使用 12px 逻辑字号。字体链增加 1px 字距，避免相邻字形粘连。文字不在对话框内部重复放大，只跟随项目 `960×540` 基准画布向实际窗口统一缩放。输出材质使用可调的覆盖率阈值；16px 下固定为 `0.25`，在保持纯黑二值输出的同时保住中文细横竖笔画，避免高阈值造成断裂。

## 在哪里填写台词

直接编辑：

`res://ui/dialogue/asset/dialogue_lines.json`

文件内容是一个 JSON 字符串数组，每个字符串就是一句话：

```json
[
  "这是第一句。",
  "这是第二句。",
  "这是第三句。"
]
```

保存文件后重新运行场景即可。句子里如果要写英文双引号，请写成 `\"`。

## 操作规则

- 文字会以打字机效果逐字出现。
- 打字过程中单击文本框，会立即补全当前句。
- 当前句完整后再次单击，会播放下一句。
- 最后一句结束后再单击，文本框会隐藏。

## 复用与调整

- 把 `res://ui/dialogue/dialogue_box.tscn` 实例化到其他场景即可复用。
- 在 Inspector 中修改 `Characters Per Second` 可以调整打字速度。
- 修改 `Dialogue File` 可以让不同场景读取不同的 JSON 台词。
- 运行时可调用 `start_dialogue(PackedStringArray([...]))` 临时播放一组台词。
