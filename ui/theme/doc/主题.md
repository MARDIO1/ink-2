# 主题

`asset/ink_attack_theme.tres` 是全项目统一 Theme：Button / Panel / ProgressBar 的 normal·hover·pressed·focus·disabled
样式都在里面，另带一个 `SystemFont`（微软雅黑 UI 等，字重 800）。`src/ink_ui_resource.gd` 是可
Inspector 编辑的设计令牌类型，`asset/ink_ui_tokens.tres` 是它的一个实例。

## 稳定接口（场景只依赖这些名字）

- Button 变体：`PrimaryButton`、`DangerButton`（普通 Button 即次要样式）
- Label 变体：`TitleLabel`、`MutedLabel`、`AccentLabel`
- 面板变体：`CardPanel`、`OverlayPanel`
- 进度条变体：`InkMeter`

以后换皮只改 Theme，场景不用动。改令牌数值要**同时**改 `ink_attack_theme.tres` —— Godot 原生
Theme 不会去读任意 Resource 的字段。

## 谁在用

`ui/menu/menu.tscn`、`ui/hud/hud.tscn`、`ui/esc/esc.tscn` 的根节点设 `theme=` 指向本 Theme；
`actor/canvas/canvas.tscn` 的工具面板同样接它。`ui/components/` 是配套的预置组件。
