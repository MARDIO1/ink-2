# 游戏指针

`cursor.tscn` 作为 `InkCursor` 自动加载，只在同一视口内有关卡玩家时接管鼠标。主菜单、关卡目录、窗口外和窗口失焦时恢复系统指针；F6 独立运行关卡同样生效。

画布内使用 `asset/canvas_cursor.png`（圆环中心为热点），可见圆环外径按当前画布的笔触直径和画布/相机变换实时缩放，最小为 12 逻辑屏幕像素，以免细笔触或远景中难以寻找；透明留边不算入笔触范围。圆环中心的黑色圆盘单独绘制，代表真实笔刷覆盖范围：1 px 笔触就是 1×1 中心像素，其余尺寸随 `brush_size` 缩放。画布外及 GUI 上使用 `asset/world_cursor.png`（箭头尖端为热点），保持 0.25 倍的固定尺寸。PNG 均使用最近邻过滤，再随项目逻辑分辨率统一缩放。

每帧根据可见、激活画布的 CanvasSurface 变换判定，支持多画布、地图编辑器及相机缩放/平移。指针为忽略鼠标输入的屏幕层，位于暂停菜单、蓝图库和转场之上，不改动点击坐标，不占用 GUI 焦点；暂停时继续跟随鼠标。

钉子、八齿/十二齿齿轮、蓝图放置，以及地图编辑器的传送门等部件放置/操纵模式使用固定大小的箭头；恢复绘画工具后立即恢复笔触圆环。只读取工具状态，不拦截或改写放置事件。
