# 主菜单

`menu.tscn` **不是独立场景**：工程主场景 `root/root.tscn` 把它挂进 `UI` 容器，当**第一屏**。
「开始」只对 root 喊一声 `start_pressed`（换屏归 root，它接着挂 `ui/level_select`）；
「退出」关闭程序，ESC 等同退出。

按钮样式改走共享 Theme `ui/theme/asset/ink_attack_theme.tres`（`PrimaryButton` / `DangerButton` /
`CardPanel`…），场景里不再内联 StyleBox；标题图与纸底仍用 `asset/` 里那几张。

## 尺寸

按参考工程 `T:\GODOT\bag\BackGround` 等比移植：参考逻辑视口 4096×2560，本工程 960×540，
比例 s = 960/4096 ≈ 0.2344。

绝对值一律乘 s：字号 104→24、按钮图标宽 96→22、边框 13→3、焦点边框 19→4、圆角 5→1、
投影 7 / 偏移 13→2 / 3、内容边距 54/20→13/5。**锚点比例原样不动**，所以窗口放大时观感与参考一致
（2560 宽窗口下 `canvas_items` 放大约 2.67 倍，等于参考在 1280×800 窗口下的相对大小）。
