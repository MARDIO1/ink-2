# 主菜单标题：交互水面（常驻 + 鼠标涟漪）

**自成一体**：不引用工程里的任何场景 / 脚本 / 源码，只用 `ui/menu/asset/title.png` 与
`paper.png` 两张图片素材。

```
godot --path . res://ui/menu/title_fx/demo.tscn     # 空格 = 开关，ESC = 退出
```

## 两层叠加

| 层 | 是什么 | 参数 |
| --- | --- | --- |
| **一、全局水面** | 多方向、多尺度、缓慢漂移的**噪声波场**（大涌/中波/细纹/碎纹 + 域扭曲）—— 水面**平时就一直在动** | `sea_scale=3` `sea_speed=0.14` `sea_amp=0.55` `octave_falloff=0.62` `detail=0.90` `warp=0.40` |
| **二、涟漪模拟** | 波动方程跑在两张互相引用的 SubViewport 里，鼠标移动与环境落点注入 —— 会传播、会干涉的尾迹 | 见下方 `ripple_sim.gdshader` |

两层的高度与梯度相加，再统一做折射 + 掠射反光。

⚠️ **两层的尺度必须各自独立**：噪声水面的梯度量级约 0.5，模拟的梯度约 0.5/**纹素** ——
差一个量级。混用一个 `strength` / `normal_scale` 的话，要么水面看不出来，要么笔画被推糊。

| 参数 | 全局水面 | 涟漪模拟 |
| --- | --- | --- |
| 折射位移 | `sea_strength = 0.0012` | `sim_strength = 0.010` |
| 坡度系数 | `sea_normal = 0.45` | `sim_normal = 9.0` |

⚠️ 中途我把层一删掉过一次（改"鼠标移动起涟漪"时整份替换了 shader），结果水面平时变成静止的 ——
两层要**同时**留着。

## 做法：参考网上的交互水实现

参考 **Namey5/godot-interactive-water**（Godot 4.3）与它引的 Hugo Elias 水面算法：

> A [-1,1] heightmap containing both current and previous moments (in RED and GREEN channels),
> ping-ponged into a new buffer, spatially dispersing the current height and rotating the moments.
>
> **a ViewportTexture cannot reference its own Viewport, so we need a nested Subviewport
> to get working double-buffering (yes, the viewports reference each other)**

关键就是最后这句 —— **Godot 里 ViewportTexture 不能自引用**。我先前按本地参考 `D:\ink-research\giw`
试的自引用因此失败（读回来 R 恒为 0.945、帧间差 0.00）。可行做法是：

1. **两张 SubViewport 互相引用**：A 读 B、B 读 A。Godot 按树序渲染 —— A 先渲染（读到 B 的上一帧），
   B 再渲染（读到 A 的这一帧），每帧刚好推进一步，等价于双缓冲乒乓。
2. 状态编码：**R = 当前高度，G = 上一帧高度**（都压到 0..1），用来算时间导数。
3. 更新：`h = (2*当前 - 上一帧 + 拉普拉斯*speed) * damp`。
4. 标题 shader 取高度场的**梯度**做折射位移与法线，再由法线算掠射反光。

| 文件 | 作用 |
| --- | --- |
| `ripple_sim.gdshader` | 波动方程（挂在一张没有贴图的 ColorRect 上，格子尺寸由 `sim_size` 给） |
| `ripple_title.gdshader` | 标题：梯度 -> 折射 + 法线 -> 掠射反光 |
| `demo.gd` | 两张互相引用的 SubViewport、鼠标注入、环境落点 |

## 鼠标交互

**只有移动才注入**：光标每移动一点就往模拟里压一下，于是拖出一串会传播、会互相干涉的尾迹 ——
这是"运动涟漪"的关键（程序化的独立环波没有这种耦合，所以当时"没有运动涟漪的感觉"）。
静止的光标什么也不做，不做静态小坑。录视频时没有真鼠标，demo 会自动扫一条 Lissajous 路径。

## 参数总表

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `damp` / `speed` | 0.986 / 0.32 | 衰减 / 扩散速度（>0.5 会发散） |
| `mouse_radius` / `mouse_amp` | 0.045 / 1.30 | 光标扰动半径 / 强度 |
| `strength` | 0.035 | 折射位移：0.055 时笔画边缘偏碎 |
| `normal_scale` | 9.0 | 高度梯度 -> 坡度 |
| `align_min` / `spec_strength` | 0.80 / **0.12** | 朝光要多准才反光 / 反光强度（0.35 时中间调 12%，字发灰） |
| `diffuse` | **0** | 有符号漫反射；>0 会在黑墨上铺灰，看着脏 |

## 边界与范围

- **吸收边界**：`h *= mix(0.90, 1.0, smoothstep(0.0, border, edge))` —— 靠边 7 个纹素内额外衰减，
  涟漪撞墙就耗散掉，不会弹回来（不处理的话硬边界会把波原样反射，画面会"回声"）。
- **范围**：扰动半径 `mouse_radius` 与整体衰减 `damp` 一起决定一颗涟漪能波及多远。
  0.045 / 0.986 -> 0.025 / 0.978 -> **0.015 / 0.970**（两次收紧）。

## ⚠️ 踩过的坑

1. **ViewportTexture 不能自引用**（见上）—— 必须两张 viewport 互相引用。
2. **SubViewport 的子 ColorRect 必须显式给尺寸**：SubViewport 不是 Control，锚点撑不开，
   尺寸会是 0，什么都不渲染（症状：模拟贴图恒定不变）。
3. **纯黑贴图不能用 `COLOR *=`**：canvas_item 里 COLOR 进来时已等于 `texture(TEXTURE, UV)`，
   而 title.png 是纯黑 —— 必须 `COLOR = vec4(ink, a)` 赋值，否则涟漪/反光全部看不见。
4. **黑墨上"灰"读起来是脏**：`diffuse` 与起伏明暗都必须为 0，水只以反光出现。

## 性能开销（实测）

用模块里的 `perf.gd` 探针实测（OpenGL Compatibility 渲染器，与工程设置一致；`--disable-vsync`）：

```
godot --path . --disable-vsync --script res://ui/menu/title_fx/perf.gd -- <场景> <模式>
# 模式：full / novp（释放两张 SubViewport）/ nomat（摘掉标题材质）/ notitle
```

| 场景 | FPS | 帧时间 |
| --- | --- | --- |
| 纯菜单（对照） | 398 | 2.51 ms |
| 演示场景 full（全部开启） | 343~375 | 2.67~2.92 ms |
| — 释放两张 SubViewport | 393 | 2.54 ms |
| — 摘掉标题材质 | 384 | 2.60 ms |

**结论：整套特效约 0.3~0.5 ms，约占 60 FPS 预算（16.7 ms）的 2~3%，可以忽略。**
模拟两张 viewport 各 192×108（合计约 4.1 万像素/帧），标题 shader 覆盖约 23 万像素/帧；
显存 2 × 192×108 × 4B ≈ **166 KB**。

⚠️ 有一次首次测量得到 1.0 FPS，但**无法复现**（删掉 shader 缓存冷启动仍是 375 FPS）——
当时机器上还有别的 Godot 进程在跑。如果真机上出现掉帧，先查是不是这个原因。

## 调试招数（都验证过有效）

1. **把中间量直接画出来**：`COLOR = vec4(vec3(clamp(h*0.5+0.5,0,1)), a);` —— 一眼看出模拟的真实形态。
2. **染色测试**：`COLOR = vec4(1,0.1,0.1,a);` —— 确认渲染走的确实是当前 shader。
3. **删掉 `.godot/shader_cache`** 再录，排除编译缓存干扰。

## 已实装到主菜单

主菜单标题现在带这个特效。改动**只有两处**：

1. `ui/menu/menu.tscn`：加了一行 ext_resource + `Title` 下的一个节点
   ```
   [node name="TitleWater" type="Node" parent="Title"]
   script = ExtResource("7_water")
   ```
2. `ui/menu/title_fx/`：本模块（两个 shader + `title_water.gd`）

`title_water.gd` 挂在 `Title` 下面，父节点就是要作用的 TextureRect，**不改 `menu.gd`**，
也不依赖工程里其它代码。关掉特效：把该节点的 `enabled` 取消勾选（或删掉这个节点）。

⚠️ 注意 `menu.tscn` 是 **CRLF** 行尾 —— 用脚本改它时多行匹配要写成 `\r?\n`，
否则替换会静默失败（我第一次就栽在这，节点没进去、特效自然没生效）。

实装后实测：真菜单录制帧间差 **1.34**（无鼠标、只有环境涟漪；演示场景带自动鼠标路径时是 2.32）。

## 接到别处

需要每帧喂 `mouse`（`ripple_sim` 的 uniform），并搭两张互相引用的 SubViewport —— 这部分在
`demo.gd` 里可以直接抄。标题本身只挂一个 `ShaderMaterial`（`ripple_title.gdshader`）。
