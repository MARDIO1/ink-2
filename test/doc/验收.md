# 验收

使用 Godot 的 `--headless --path` 参数，分别运行：

```text
--script res://test/test_hand_physics.gd
--script res://test/test_canvas.gd
--script res://test/test_ink.gd
--script res://test/test_upright.gd
--script res://test/test_red_ink.gd
```

## 目录约定

- `test/` **顶层只放验收脚本**（上面这些；另有 `test_game_control` / `test_collision_damage` /
- `test/` **顶层只放验收脚本**（上面这些；另有 `test_game_control` / `test_collision_damage` /
  `test_live_input` / `test_ccd_debris`）。
  `test_hand_jitter` 不是验收脚本：它没有断言、`quit()` 也不给退出码，是 8 组阻尼参数的性能对照台。
  同理，`test/probe_*.gd` 是标定探针（按约定本该在 `test/tools/`）。
- `test/tools/` 放**标定与性能工具**（`calibrate_collision_damage.gd`、`profile_collision_damage.gd`、
  `bench_small_fragment_ccd.gd`），原则上不参与验收（`calibrate_collision_damage.gd` 例外，它自带
  4 条 `_check` 并 `quit(1 if failures else 0)`；`profile_red_ink.gd` 另带完整窗口场景的功能/性能退出码）。
- **人用的调试工具不在 test/**：在 `debug/`（`debug/hud` 调试 HUD + 力观察器、`debug/creative` 创造模式），
  由关卡实例或独立跑。分工见 `doc/文件组织.md`。

测试包括关节长度与角度、抓物抬起、抓地及物块支撑、反作用力、动量和主动功率预算，
以及换美术贴图不动物理（`test_hand_physics.gd` 的 `pose/*` 四条）。
动量测试关闭外部阻尼；有重力和接触的场景按执行器做功检查能量预算。

`test_ink.gd`：墨水图层 `BottledInk`（33 检查）。⚠️ **这份脚本现在是坏的**：`:129` 还在 `get_node("BottledInk/Liquid")`，而 PBF 流体改造后 `Liquid` 子节点已经删掉 → `get_node` 报错、`:141` 对 null 调 `has_method` 让协程中断、`quit()` 永远到不了 → headless 卡死（日志停在 `PASS BottledInk is not a shape node`）。33 条断言里约 21 条仍有效、12 条描述的是旧的 `Liquid` 实现。要用它当闸门，得先按 `bottled_ink.gd` 的 `_build_container()` / `_draw` / `_render()` 重写。

`test_upright.gd`：世界竖直回复力矩（18 检查）。正常撞击不倒、极限翻滚收得住、关掉控制器后同样的撞法必倒、腾空与手抓握世界时力矩恒为 0、力矩不超上限。

`test_live_input.gd`：真实按键路径，走路与跳跃。加 `-- --grip` 走抓握分支，`-- --grip --right --rotate`（可再叠 `--climb`）走抓地摆动分支。

`test_red_ink.gd`：33 项红墨回归，当前32通过、1失败。测试读取实际红墨资源强度；降低强度至50后，4×4小装药跨空气连锁通过，但原薄炮尾后坐断言失败，不能宣称功能全部通过。
覆盖普通裂纹破坏内层红墨、轻撞不触发、下一 tick 反应、
炮弹前冲/炮身受力、薄壁分片向外抛射、跨空气连锁、源体删光后事件仍存在，以及封闭对称壳的动量抵消。
这些测试用明确接触输入检查伤害接口，不替代真实碰撞场景。
另覆盖独立事件分组、第二轮穿过已删除前壁命中后壁、离轴碎片不被强行分配冲量、第二轮不生成伤害。

`test/tools/profile_red_ink.gd`：去掉 `--headless` 运行。使用真实 Rapier 碰撞、
现有 `PhysicsRuntime`、游戏默认分片/灰尘策略、渲染和 F1 探针，暖机后记录 600 帧。
分别撞击灰墨炮尾与薄壁手榴弹，检查炮弹实际收到前向爆炸冲量、炮管碎片收到后向冲量、
手榴弹红墨反应及灰尘向外飞。1% low 低于 50 FPS 或功能失败时 exit 1。
完整帧记录和摘要在 `user://red_ink_profile.jsonl`、`user://red_ink_profile_summary.json`，
F1 低帧仍记录在 `test/low_frames_*.jsonl`。当前薄炮尾会被裂纹打断，该场景验证分片受力，
不能当作“完整炮管稳定后坐”的验收；最慢单帧也单独报告，1% low 达标不代表每帧都达标。
加用户参数 `-- --capture` 可以另跑截图模式，保存 `user://red_cannon.png` 和
`user://red_grenade.png`；截图读回与 PNG 写入会阻塞，因此该模式不执行 50 FPS 性能判定。
加 `-- --player-size` 使用玩家68×87物理外接尺寸的实心红墨；
可再加 `--event-size=32` 比较事件分组。该模式保存 `user://red_ink_player_profile.jsonl`
及同名前缀摘要，不覆盖小装药结果。整组消耗后的玩家尺寸专项1% low已超过50，
最慢单帧仍超过20 ms；当前强度50的窗口工具性能达标，但因抛射碎片不足exit 1，不能视为完整功能验收，详见 `红墨验收.md`。
