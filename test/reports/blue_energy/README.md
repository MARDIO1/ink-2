| 长度 px | CPU 中位数 µs | CPU P95 µs | 活跃格更新次数 |

| 240 | 19 | 24 | 33460 |

| 1024 | 41 | 56 | 143220 |
| 2048 | 82 | 90 | 286580 |

长度从 240 到 4096 为 17.07 倍，更新工作量约 17.13 倍；没有遍历所有可能路径导致的指数增长。活动格状态合并、有寿命且波号抑制回头访问，分叉不会生成无限独立对象。初次登记/存储仍随导线面积增长。

## 计时火焰图与修复点

[flame.svg](flame.svg) 来自采样阶段累计的真实计时嵌套，悬停可看数值；`flame.folded` 的单位是微秒。它是计时火焰图，未伪造原生 CPU 采样栈，也没有把它当作整帧的 GPU/物理剖析。

主要修复：移除全局图和最宽路径；数值推进独立放入 ink/native；红色候选按材料块取样；远处烧断不再重建所有电源接触；局部擦除不复制整条保存数组；二进制输出按活跃数据增长；静态导线和高光分别缓存绘制；同步双缓冲保留桶容量，局部洪泛直接在波头上打标记，避免逐格建立临时集合节点。

## 边界与复测

压力图使用完整关卡的 SimulationRuntime/Rapier、实际材料和电机，但 2478000 像素的黑色载体设为静态；它验证能源路由/消费/短路，不代表大量运动刚体的物理压力。燃料储能调高以防测成空载，真实耗料由端到端测试覆盖。

构建本身仍约 11–13 秒，首次物理/渲染还有约 2 秒冷启动尖峰，均与稳态 FPS 分开记录。内存独立采样见 `chaos_memory.json`：游戏工作集约 588 MiB，观测峰值约 712 MiB，私有内存约 752 MiB；包含完整场景和大画布，不是蓝墨模块单独占用。本次未单测同进程卸载后的回收曲线。

当前原生库只交付 Windows x86_64；其他平台需构建对应库。性能结论针对本机和上述确定性地图，不保证任意规模/任意硬件的最低帧。
