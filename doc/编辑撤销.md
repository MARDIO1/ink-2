# 编辑撤销

地图编辑器与游玩画布使用 Ctrl+Z 撤销内容修改，按操作的先后顺序倒序恢复。

- 画笔、橡皮、形状、填充、钉子：整次笔触为一步。
- 清空：恢复原像素、钉子、黄墨草稿及本次清空返还的墨水数量。
- 固化/实体化：移除本次生成的实体，恢复原画布及黄墨草稿。
- 墨化：恢复操作前的实体、速度、固定状态及画布，保留钉子。
- 框删：恢复实体状态和画布像素，包括局部切割产生的分片。
- 四侧扩展：恢复画布尺寸、位置、墨水和钉子；扩展前的笔触可继续撤销。
- 怪物、文本、对话、复活点、画布、传送门：沿用编辑器的新增、删除、移动、缩放和目标修改记录；删除恢复后仍可继续撤销之前的移动/缩放。

切换工具、选色、调节笔触粗细、显示/隐藏工具栏、打开或关闭子菜单不修改已有内容，不占撤销步骤。保存和切换地图不回滚磁盘文件；撤销历史只在当前会话中保留。

按钮事务使用压缩像素快照；墨化/框删只保存与操作范围相交的非生物实体，不回滚玩家或怪物的实时物理状态。玩家墨水仅补偿该操作造成的变化，不恢复历史血量。
