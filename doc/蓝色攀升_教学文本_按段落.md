## 02 伸桥过沟

```text
② 蓝墨·形状→矩形 7px
从红墨左侧短蓝线起笔，沿黑色横条向左拖。
箭头朝左，再按「固化」；动力会拉断黄墨保险簧。
等桥伸到左岸，向左过桥，再沿黑坡向上走。
```

## 03 转桥成坡

```text
03  转桥成坡 →
```

```text
③ 先走到平桥中段；切蓝墨·画笔 7px。
找到右侧下悬黑臂底部、红墨右边的两段蓝线。
竖着补齐蓝线缺口，再按「固化」。
等桥向右上方抬起，沿桥上行，从右端短跳上岸。
```

## 04 弹簧牵引

```text
黄墨：连接两箱内侧黑座 ↓
```

```text
高箱：向左蓝箭头 ↓
```

```text
④ 黄墨·画笔 12px：连接两箱相邻的黑色安装座，固化。
切蓝墨·形状→矩形 7–12px。
从高箱红墨左侧短蓝线，沿黑色横条向左拖出箭头。
再按「固化」，等高箱牵引矮箱一起向左停靠。
从右侧跳上矮箱，再跳上高箱，最后向左上岸。
```

蓝墨·矩形 12px

## 05 黄墨配重摆渡台

```text
05  黄墨配重摆渡台 ↖
```

```text
⑤ 双黄杆与配重摆渡台
从左侧台阶落到黄杆，沿黄杆缓坡走上右侧黑色踏台。
蓝墨·形状→矩形 12px：从黑臂底部红墨旁的蓝点起笔，
沿黑臂竖直向上画箭头，再按「固化」。
双黄杆保持踏台水平，左端配重辅助向左上摆升。
等停稳后向左落到接落台，沿黑坡向左上行。
```

## 06 齿轮传动提闸门

```text
从长坡顶端向左上短跳，落到左上黑台；
沿左上方黑坡和两块短台阶前进，
再向右上方短跳，返回第⑥段桥前。
```

```text
蓝墨·画笔 15px：在齿轮左侧，补齐红墨与黄轴之间的蓝线缺口。
蓝线沿黄轴向齿轮供电；黑轮左侧的向上箭头带动齿轮、提起闸门。
门停稳后，从桥面下方通过。
```

```text
⑥ 齿轮提闸门
站上左侧短台阶，选蓝墨·矩形 12px。
从黑轮左下短蓝点起笔，向上画箭头并固化；不要从轴心起笔。
```
