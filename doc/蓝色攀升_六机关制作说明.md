# 蓝色攀升：六段墨水机关

原地图：`map/asset/imported/蓝色攀升.tscn`。当前构建入口为 `tools/build_blue_ascent_linkages.gd`，继承前三段的制作方法，为第二段增加黄墨保险簧，重做后三段及第五段出口附近地形。默认输出 `.codex-tmp/blue_ascent_machines_work.tscn`；制作过程中先备份原地图，验证后再写回。

| 段落 | 玩家操作与实际运动 |
| --- | --- |
| 01 通电开门 | 补门底蓝线，现成蓝箭头提升门；实体顶部挡块限位。 |
| 02 伸缩桥 | 在桥尾黑墨区画7px向左蓝箭头，红墨供能，拉断预拉黄墨保险簧后沿黄轨左移并靠实体挡块停下。保险簧抵住小人直接推动。 |
| 03 转桥成坡 | 补下悬臂蓝线，现成箭头抬桥；后臂托在斜支座上停靠。 |
| 04 弹簧牵引双箱 | 黄墨画笔12px连接两箱内侧加厚黑座；蓝墨矩形7–12px在高箱红墨左侧画向左箭头。双箱各有黄墨保险簧，只有高箱有动力，矮箱靠弹簧牵引，最后形成台阶。 |
| 05 蓄能弹射 | 双主弹簧预装。蓝墨矩形24px沿右侧黑臂向下画箭头，将踏台压低；踏上凸起杠杆，真实红墨接点移离蓝线，断电后弹簧回弹。向左落到宽台或黑坡，再沿黑坡步行上层。 |
| 06 单源桥门联动 | 黄墨画笔12px连接左岸黑座与桥后臂，作为回位弹簧；走到桥中段，蓝墨矩形20px顺下悬黑臂朝桥面画箭头。桥转动时，预装的正常黄墨压簧推起门；门没有独立电源或箭头。 |

红墨电源和承载黑墨结构预置；玩家组合黄墨连接与蓝墨施力。建议笔刷宽度写在画布旁，工具栏沿用游戏正常的颜色和工具切换。第四至六段画布初始笔刷为12/24/20px，其他为7px；游玩时切换画布仍尊重已有工具栏状态，需要时按提示调整。

## 结构约束

- 导轨钉、转轴和弹簧全部使用现有黄墨组件；没有启用关节角度或位移上下限。
- 平移和转角终点由实际墨水挡块、支座、箱体接触决定。
- 第五段没有召回按钮、计时释放或代码驱动。脚踏杠杆通过质量、弹簧和转轴运动，让红墨端子与蓝线真实接触、分离；黄墨拉簧越过转轴死点后保持断电，实体支座承托两端位置；重置关卡恢复初始蓄能状态。
- 第二、四段的保险簧沿用普通黄墨的预拉与过载断裂规则，窄颈使用现有磨损数据形成。小人持续推动不足以拉断，蓝墨动力和双箱牵引簧能够释放；没有降低角色推力、改变墨水强度或添加脚本解锁。
- 第六段删除黑墨连杆及其两个转轴，改用50px正常黄墨压簧，原长比初始锚点间距长18px。初始压力不足以顶起门；桥抬起后继续压缩弹簧，产生足够向上推力。黄墨弹簧按原有规则不挡行人，无需背景钉或额外碰撞设置。
- 第五段删除踏板上两条细小配重笔画；保留承力臂、端子与必要支座，重建为干净初始结构。
- 固定支承有固定钉；持续承压的挡块另装无限钉，避免长期通电把挡块压碎。无限燃料钉保持教学红墨供能，不固定活动体。
- 基础地形与落脚面保持黑墨；第五段旧出口台下缘薄化、右缘退让，给新黑坡留出净空。

本关通用物理配置仍使用上一版的旋转阻尼和碰撞纠偏参数；黄墨弹簧阻尼比设为0.08，减少回弹振荡。第五段两根主簧为33px、原长420px，实体挡块留出约195px压缩行程；脚踏过中心拉簧为30px，原长比两锚点初始间距短60px。均通过现有墨水物理字段实现，没有增加机关专用运动脚本、输入或限制。

## 验证与性能

当前定向测试为 `test/test_blue_ascent_linkages.gd`，通过实际画布生成黄墨弹簧和蓝箭头，验证普通关节、双箱牵引、脚踏断电、弹射接落点、桥门机械联动，以及第五段出口衔接。窗口检查使用1.0和1.15缩放核对绘制点与工具栏；不重复整关通关。

记录与预览保存到 `output/blue_ascent_linkages/`。性能数值为本机模拟CPU采样，不能当作实际显示FPS；测试扩大了物理活动范围，使后三段同时运行。旧版 `test_blue_ascent_all_machines.gd` 仅保留测试辅助方法，其旧完整用例不作为当前后三段的验收入口。

2026-10-19 最新定向验收：`test/test_blue_ascent_linkages.gd -- --work --section=linkage --mechanics --push-proof` 43项通过，包括第二、四段抗推与蓝墨释放、第五段弹射接落台与返回上层、第六段压簧提门及步行穿门，全程不抓握。本轮没有修改角色控制、墨水规则或物理运行代码。模拟CPU采样中位4.549ms、P95 7.172ms、最大9.004ms；该数值不代表实际显示帧率。工具区1.0/1.15缩放和编辑器基线43项检查沿用上一轮结果，没有重复完整通关。

第五段上升时需要按住左移，在离开踏面前带出横向速度；沿用正常移动操作。接落台右沿与踏台保持净距，避免顶头或妨碍蓄能；加宽的120px踏板留出起步距离。重建时也按脚本类型清理编辑器重存后的匿名黄墨组件，避免旧导轨、轴钉重复参与物理。
