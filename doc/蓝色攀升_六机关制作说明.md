# 蓝色攀升：六段墨水机关

原地图：`map/asset/imported/蓝色攀升.tscn`。当前构建入口为 `tools/build_blue_ascent_linkages.gd`，继承第一至第三段的制作方法，仅重做后三段及第五段出口附近地形。默认输出 `.codex-tmp/blue_ascent_machines_work.tscn`；制作过程中先备份原地图，验证后再写回。

| 段落 | 玩家操作与实际运动 |
| --- | --- |
| 01 通电开门 | 补门底蓝线，现成蓝箭头提升门；实体顶部挡块限位。 |
| 02 伸缩桥 | 在桥尾黑墨区画向左蓝箭头，红墨供能，桥沿黄轨左移并靠实体挡块停下。 |
| 03 转桥成坡 | 补下悬臂蓝线，现成箭头抬桥；后臂托在斜支座上停靠。 |
| 04 弹簧牵引双箱 | 黄墨画笔7px连接两箱内侧加厚黑座；蓝墨矩形7px在高箱红墨左侧画向左箭头。只有高箱有动力，矮箱靠弹簧牵引，最后形成台阶。 |
| 05 蓄能弹射 | 双主弹簧预装。蓝墨矩形24px沿右侧黑臂向下画箭头，将踏台压低；踏上凸起杠杆，真实红墨接点移离蓝线，断电后弹簧回弹。向左落到宽台或黑坡，再沿黑坡步行上层。 |
| 06 单源桥门联动 | 黄墨画笔12px连接左岸黑座与桥后臂，作为回位弹簧；走到桥中段，蓝墨矩形20px顺下悬黑臂朝桥面画箭头。桥转动时，黑墨连杆经两个黄墨转轴同步提门；门没有独立电源或箭头。 |

红墨电源和承载黑墨结构预置；玩家组合黄墨连接与蓝墨施力。建议笔刷宽度写在画布旁，工具栏沿用游戏正常的颜色和工具切换。画布初始笔刷为7/24/20px；游玩时切换画布仍尊重已有工具栏状态，需要时按提示调整。

## 结构约束

- 导轨钉、转轴和弹簧全部使用现有黄墨组件；没有启用关节角度或位移上下限。
- 平移和转角终点由实际墨水挡块、支座、箱体接触决定。
- 第五段没有召回按钮、计时释放或代码驱动。脚踏杠杆通过质量、弹簧和转轴运动，让红墨端子与蓝线真实接触、分离；黄墨拉簧越过转轴死点后保持断电，实体支座承托两端位置；重置关卡恢复初始蓄能状态。
- 第六段连杆使用真实背景钉放在后层，保留质量与关节传力，杆身不会堵住行人通路。
- 固定支承有固定钉；持续承压的挡块另装无限钉，避免长期通电把挡块压碎。无限燃料钉保持教学红墨供能，不固定活动体。
- 基础地形与落脚面保持黑墨；第五段旧出口台下缘薄化、右缘退让，给新黑坡留出净空。

本关通用物理配置仍使用上一版的旋转阻尼和碰撞纠偏参数；黄墨弹簧阻尼比设为0.08，减少回弹振荡。第五段两根主簧为33px、原长420px，实体挡块留出约195px压缩行程；脚踏过中心拉簧为30px，原长比两锚点初始间距短60px。均通过现有墨水物理字段实现，没有增加机关专用运动脚本、输入或限制。

## 验证与性能

当前定向测试为 `test/test_blue_ascent_linkages.gd`，通过实际画布生成黄墨弹簧和蓝箭头，验证普通关节、双箱牵引、脚踏断电、弹射接落点、桥门机械联动，以及第五段出口衔接。窗口检查使用1.0和1.15缩放核对绘制点与工具栏；不重复整关通关。

记录与预览保存到 `output/blue_ascent_linkages/`。性能数值为本机模拟CPU采样，不能当作实际显示FPS；测试扩大了物理活动范围，使后三段同时运行。旧版 `test_blue_ascent_all_machines.gd` 仅保留测试辅助方法，其旧完整用例不作为当前后三段的验收入口。
