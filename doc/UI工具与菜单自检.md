# 工具与菜单交互

## 补齐的入口

- 主菜单声音设置：复用 ESC 声音子页，返回时直接回封面，不露出游戏暂停菜单。
- 关卡选择返回按钮与 Esc：加载过程中禁用返回和重复选关；加载失败恢复。
- ESC 操作说明：可滚动查看游玩、绘画、框选、地图编辑器和蓝图快捷键。
- 画布色盘旁撤销/重做：游玩时只操作所属画布；编辑态走 Creative 的混合时间线。
- 编辑器右侧撤销/重做、保存地图、小人显示、钉子显示。保存按钮只打开确认窗口；空名称、无效目录和保存失败显示原因。
- 蓝图库分页首尾禁用、选中卡片标记、搜索无结果清空过期详情及使用状态。

图片导入在现有代码中已明确停用，仅保留旧图片删除的撤销恢复，因此不重新开放入口。

## 统一按钮反馈

`UIFeedback` 自动加载为场景按钮和动态创建按钮安装 `ButtonFeedback`。保持原纸墨配色，通过短墨线和按下反馈区分状态，不再绘制焦点/选中四角外框；统一按钮主题的额外焦点外框也已取消。不改变命中区域、业务信号或文字布局，键盘导航和确认继续有效。工具原图继续单独缩放，禁用时变淡；隐藏、失焦、禁用时清理残留按下状态。色盘保留自己的圆形选择标记。

反馈节点不接收鼠标事件、不增加 `pressed` 业务回调、不设置场景 owner，因此不会被保存进地图。

日志打开时暂停世界，关闭恢复先前暂停状态。日志、蓝图库、暂停菜单避免叠加；Esc 每次只返回当前子页，不能穿透并同时打开另一层菜单。

## 回归入口

使用 `D:\Godot\Godot_v4.7.2-stable_win64_console.exe --headless --path D:\Ink --script res://test/<测试名>.gd`。

- `test_ui_interactions`：147 项场景按钮绑定、真实鼠标点击、ESC、模态切换、蓝图分页/过滤、显示开关、保存校验、目录选择/取消及撤销重做检查。
- `test_ui_feedback`：26 项重复安装、悬停、按下、隐藏、禁用、失焦、选择状态、色盘、命中区域及额外焦点框检查。
- `test_ui_interactions -- --preview`：有渲染器时额外保存主菜单、关卡选择、暂停、帮助、蓝图库和编辑器截图至 `user://ui_audit_*.png`。
- `test_ui_interactions -- --quit-main` / `--quit-esc`：独立进程检查两处真实退出按钮。
- 继续回归已有声音设置、HUD/Tab、画布快捷键、蓝图按钮、混合撤销重做、钉子、齿轮、传送门、复活点和编辑操纵测试。

测试使用独立声音配置和临时蓝图库；地图编辑测试关闭自动保存，不改写用户地图/快照。部分物理场景退出时仍有已有的资源泄漏告警，不等同于按钮交互断言失败。
