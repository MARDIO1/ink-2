# 地图传送门

地图编辑器中打开“工具”，滚动到“地图与布局”：

- 选择目标地图，再点击“新增传送门”，在地图上单击放置。放好一个后自动退出放置模式并切换到操纵工具；需要继续添加时再次点击“新增传送门”。
- 按 F 选择操纵按钮，拖动传送门的中央洞口来移动。
- 操纵模式下，右键单击传送门中央可删除，Ctrl+Z 可撤销。
- 修改已放置的入口：按 F 进入操纵工具，左键选中入口，在传送门行的下拉框直接选择目标地图，无需单独的设置或应用按钮。
- “删除传送门”后单击入口删除。添加、删除、移动、目标修改都支持 Ctrl+Z。
- 正常保存地图会保留入口的位置、尺寸和目标；不需要修改地图文件代码。

“地图与布局”按复活点、画布、传送门分为三行，移除设置传送门和停止布局按钮。编辑模式中传送门上方显示“通往：地图名”，未指定或目标不可用时显示提示；游玩时不显示此标签。

游玩时玩家真实碰撞壳与洞口中央连续重合 2 秒后开始异步切关；离开洞口会清零计时。入口外围的细裂纹不触发传送，编辑模式也不触发。黄色圆弧显示重合进度，同一次进入只发起一次请求。

“下一关（地图列表顺序）”使用关卡选择界面的已排序列表，不循环回第一关。最后一关或目标文件失效时不退出当前地图，入口提示设置目标。推荐为正式关卡指定明确的目标地图，避免新增/改名地图改变默认顺序。

素材 `actor/portal/asset/torn_paper_portal.png` 由用户提供的“纸中间破洞效果.png”通过内置 imagegen 去背景获得，提示词要求去除横线纸张背景和中央黑色，仅保留原撕裂边缘、纹路及纤维阴影；外围和中央均为真实透明 alpha。

素材与默认显示尺寸均为 150×150 像素，触发区域随显示尺寸同步缩小。内置 imagegen 的后续编辑提示词要求仅把饱和度降至原来的约 20%，保持原撕裂形状、纸纤维、明暗和中央及外围透明，不增加任何背景；最后做 150×150 的资源分辨率归一化。

第二次编辑提示词要求合并相邻近似灰白、灰褐色块，用约 5–7 种低饱和度纸张/阴影主色减少碎点和细密纹理，保留原破洞轮廓、主裂纹及折边明暗；透明中心和外围不变。

游戏显示时洞口中央叠加 30% 不透明度的浅灰色滤镜（RGB 0.78）。遮罩从素材透明中心提取，只填充裂纹包围的洞口，素材外围仍透明；遮罩缓存共用，不逐帧重新生成。滤镜不改变传送检测与尺寸。

实现使用 PixelWorld 的玩家碰撞壳，而非单独的 Area2D；常规入口共用 Root 的异步关卡路由，直接 F6 运行地图也有切关支持。没有给现有地图自动添加入口，也没有更改关卡顺序。
