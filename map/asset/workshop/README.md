# 第一关：未完成的山间工坊

第一关场景：`res://map/asset/imported/第一页.tscn`。

路线：起点墨泉 → 缓坡 → 360px 断沟（下方回收路线）→ 配重工坊 → 谷地盾兵/高台投弹敌人 → 杠杆工坊 → 上山 → 纸洞出口。暂不加入白墨侵染。

角色约 68×87px；工坊屋顶宽 570px，通行净高约 164px；地图可编辑区域 6656×1408px。四名敌人分别位于坡顶、谷底、高台和登顶路上，墨泉与机关操作区留出安全空间。

## 美术与碰撞

屋顶按黑白手绘建筑参考重新生成，源图为 `roof_modules_source.png`。生成规格：严格侧视、透明底、粗黑像素轮廓、灰色屋面、开放桁架；三个模块为烟囱工坊、齿轮工坊、山顶门亭。游戏内图像经最近邻缩小、透明度和灰度阈值转成现有黑/灰墨水材质。

`roof_0.png` 等为处理后的参考预览；实际关卡将对应材质图嵌入 PixelShape，渲染与碰撞来自同一份像素。屋顶、梁、地板、地形、门、机关和掩体均为实体，可由现有破坏系统处理。固定结构带可破坏锚点；配重与掩体可搬动。文字、画布 UI 和传送门特效沿用原有逻辑。

建筑为开放剖面，避免实体外墙堵住横版路线。升降门放在屋檐外侧，保留完整屋顶并给门留出上升空间。

## 两处机关

- 第一处：破坏细支撑的至少 5% 像素，滑轨门启动并向上移动 176px。配重自然下落；门由原生物理马达驱动，横向连线是可碰撞的示意结构，并非完整滑轮绳索模拟。
- 第二处：将绘制或现有重物放到黄色杠杆左端。达到质量阈值并压动杠杆后开门；较重配重可直接触发。门和杠杆都保留实体碰撞。
- 两扇门本身也可以被破坏，允许替代解法。
