# 墨水道具

地图里的墨水物品由 `src/ink_item.gd` 烘焙成 `PixelBody2D`。节点额外保存 `fixed_nails` 与 `background_nails` 两组局部像素坐标。

烘焙后：

- 固定钉子写入 `static_anchor_points`，并使刚体静止。
- 背景钉子写入 `background_anchor_points`，保存原碰撞层和掩码后把两者设为 0；刚体仍为动态体并参与黄色约束求解。
- 两种钉子都生成对应的 `actor/nail/src/nail.gd` 外观。
- 背景钉子会移除白墨接触效果相关标签，避免执行白墨腐蚀逻辑。

旧地图中材质 7 的像素会在加载时转换为灰色像素与固定钉子坐标。钉子恢复需延迟到世界完成刚体烘焙以后执行。
