# 传送门

可复用场景：`res://actor/portal/map_portal.tscn`。可直接拖入关卡，或由地图编辑器的“新增传送门”实例化。

- `Portal`：目标地图、显示尺寸、旋转速度与连续重合两秒的切关逻辑。
- `SpiralCenter`：洞口遮罩和每个实例独立的旋涡材质。
- `PaperFrame`：150×150 的撕纸边框，位于旋涡之上。

修改根节点的 `portal_size` 会同时调整纸框、旋涡与触发范围；根节点 `scale`、编辑器目标地图菜单、删除/移动撤销及关卡保存流程保持不变。不新增 Godot 物理碰撞体，仍检测 PixelWorld 玩家碰撞壳。

旧地图若只有挂载 `src/map_portal.gd` 的 Node2D，脚本仍会补齐旋涡并绘制纸框，无需重写地图或快照。新放置的传送门则保留场景实例引用。

读条采用纯黑白双描边进度环、刻度、向心墨点及轻微呼吸外圈；旋涡随进度加速，完成后触发一次短暂扩散环。仍需连续重合两秒；离开、进入编辑模式或目标加载失败时清理蓄力效果，暂停时动画停止。所有效果仅绘制，不改变门的位置、尺寸或物理范围。
