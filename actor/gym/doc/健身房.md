# 健身房

`actor/gym/gym.tscn`：把角色控制器的可调数值摆成旋钮，**倍率 ×0.25 ~ ×5** 即时调。

- **形态**：和 `SmallCanvas` / `MapCanvas` 一样，是关卡里的一个 `Node2D` 子节点 —— **地图装 gym**，不是 gym 装地图。
  `map/main.tscn` 末尾那个 `Gym` 实例就是它，所以调出来的手感就是真手感。
- **面板是世界物件**：`gym.tscn` 里的 `Panel`（PanelContainer）就在关卡坐标系里，
  相机怎么动它就待在原地 —— **不是**贴在屏幕上的 `CanvasLayer`。位置 = `map/main.tscn` 里 `Gym` 的 `position`
  （现在是 `(-570, 44)`，面板 435×358；开局相机贴在玩家质心，面板落在屏幕 (4, 181)→(439, 539)。想挪就拖 `Gym`）。
- **样式照 canvas**：面板挂 `ui/theme/asset/ink_attack_theme.tres`，用 `CardPanel` / `TitleLabel` / `MutedLabel`
  变体，场景里**不内联 StyleBox**（跟 `ui/menu` 一样，换皮只改 Theme）。
- **跑法**：直接跑关卡（F6 跑 `map/main.tscn`，或从 `root` 的关卡选择进），它跟着关卡一起活。
  ⚠️ 单独打开 `gym.tscn` 只是个面板，旁边没有玩家，滑块拖了也没目标 —— 别这么跑。
- **旋钮在场景里**：一行 = `Panel/Rows/Knobs` 下一个 `HBoxContainer`（`Name` / `Slider` / `Read`）。
  **加/删旋钮只动场景**：复制一行、改 `Name` 文本和两个 metadata（见下）；脚本不再有 `knobs` 表，不会两处对不上。
  顶上一行 `Panel/Rows/Header` 是 `Title` + `Toggle`（文字 隐藏 / 显示）：`Toggle` 只藏旋钮本体，
  跟 canvas 工具栏那个隐藏按钮一样。
- **打谁**：每行节点带两个 metadata —— `target_path`（相对本节点，所以是 `../Player/...`）和
  `target_prop`（该节点上的 `@export` 名）。写错会在启动时报 `push_error`，不静默跳过。

## 倍率模型

`_ready` 时把每个目标的**当前值**记成基准，滑块永远写 `基准 × 倍率`：

- 拉回 `1.00` = 原值，不会累积；
- **启动时一个值都不写**（只记基准 + 显示读数）：没拖过滑块，关卡物理就跟没它一样；
- 拖滑块写的是**运行时**的值（重开关卡就没了）：调满意了要把数字抄进 `Player` 的 Inspector
  （`player.tscn` / `hand.gd` 的 `@export`），`gym` 自己不存配置。

## 现有旋钮

| 目标 | 数值 |
| --- | --- |
| `Player/PlayerInput`（脚） | `max_force` · `max_power` · `move_speed` · `jump_impulse` · `upright_stiffness` · `upright_damping` · `max_upright_torque` |
| `Player/Arm/Hand/HandControl`（手） | `max_force` · `max_power` · `position_stiffness` · `position_damping` |
| `Player`（自身） | `shape_density_scale`（**质量**） |

这些在各自脚本里都是 `@export`（`player_input.gd` 7 个、`hand.gd` 10 个），本来就是给 Inspector 的。
**没进 gym 的**：`hand.gd` 的 `FINGERTIP` / `GRAB_RADIUS` —— 几何标定值，进旋钮只会被调坏。

## 两个坑（都踩过）

- **质量旋钮不能每帧刷**：改一次要走"逐像素扫质量 + 贪心分解 + 重推密度"（玩家 3 千多格 ≈ 2~3ms），
  所以它接的是 `drag_ended`（松手才生效），别的旋钮接 `value_changed`。
- **质量重算的密度回调必须是世界节点的 `_density_of`**（`Callable(world, "_density_of")`）：
  `PWorld.density_of_material()` 会把密度 0 兜底成 1.0 —— 玩家白标签那 1310 格会凭空多出 1310 质量。
- 改质量后力的手感不是线性的（力和功率都按质量算）：gym **不自动联动**别的旋钮，自己配。

## 一个必须守的规矩

`Gym` 必须是 `map/main.tscn` 里**排在 `Player` 之后**的子节点：它在 `_ready` 里记基准值，
排在 Player 前面就会记到 Player 还没 `_ready` 的值。

## 自测

`gym.gd` 的 `set_knob(index, mult)` 是旋钮的程序入口（`index` = 场景 `Panel/Rows/Knobs` 里的第几行），
可以在 headless 脚本里逐档验证：

```
质量 ×0.50 -> 1399.16986   ×2.00 -> 5596.67944   ×5.00 -> 13991.69860   ×0.25 -> 699.58493   ×1.00 -> 2798.33972（基准）
脚·最大力 ×2.00 -> 12000000（基准 6000000）      手·最大力 ×0.50 -> 8000000（基准 16000000）
```
