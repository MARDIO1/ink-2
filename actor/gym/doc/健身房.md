# 健身房

`gym/gym.tscn`：把角色控制器的可调数值摆成旋钮，**倍率 ×0.25 ~ ×5** 即时调。

- **跑法**：打开 `res://gym/gym.tscn` 按 **F6**。和画布一样，编辑器里看得到面板，但要拖滑块得运行起来。
- **场景**：本节点 + 一个 `map/main.tscn` 实例（真地图、真角色、真 HUD），所以调出来的手感就是真手感。
- **面板**：由 `gym/src/gym.gd` 生成（不往场景里塞一堆节点）；旋钮表是它的 `knobs` 导出，**在 Inspector 里可改**。

## 倍率模型

`_ready` 时把每个目标的**当前值**记成基准，滑块永远写 `基准 × 倍率`：

- 拉回 `1.00` = 原值，不会累积；
- 在编辑器里拖 → 写的是 `gym.tscn` 里那份**实例覆盖**（保存就存进 gym.tscn），
  `player.tscn` / `map/main.tscn` 一点不动。

## 现有旋钮

| 目标 | 数值 |
| --- | --- |
| `Player/PlayerInput`（脚） | `max_force` · `max_power` · `move_speed` · `jump_impulse` · `upright_stiffness` · `upright_damping` · `max_upright_torque` |
| `Player/Arm/Hand/HandControl`（手） | `max_force` · `max_power` · `position_stiffness` · `position_damping` |
| `Player`（自身） | `shape_density_scale`（**质量**） |

这些在各自脚本里都是 `@export`（`player_input.gd` 7 个、`hand.gd` 10 个），本来就是给 Inspector 的。
**没进 gym 的**：`hand.gd` 的 `FINGERTIP` / `GRAB_RADIUS` —— 几何标定值，进旋钮只会被调坏。

## 两个坑（都踩过）

- **质量旋钮不能每帧刷**：改一次要走"逐像素扫质量 + 贪心分解 + 重推密度"（玩家 3 千多格 ≈ 2~3ms），
  所以它接的是 `drag_ended`（松手才生效），别的旋钮接 `value_changed`。
- **质量重算的密度回调必须是世界节点的 `_density_of`**（`Callable(world, "_density_of")`）：
  `PWorld.density_of_material()` 会把密度 0 兜底成 1.0 —— 玩家白标签那 1310 格会凭空多出 1310 质量。
- 改质量后力的手感不是线性的（力和功率都按质量算）：gym **不自动联动**别的旋钮，自己配。

## 自测

`gym.gd` 的 `set_knob(index, mult)` 是旋钮的程序入口（`index` 见 `knobs` 顺序），
可以在 headless 脚本里逐档验证：

```
质量 ×0.50 -> 1399.16986   ×2.00 -> 5596.67944   ×5.00 -> 13991.69860   ×0.25 -> 699.58493   ×1.00 -> 2798.33972（基准）
脚·最大力 ×2.00 -> 12000000（基准 6000000）      手·最大力 ×0.50 -> 8000000（基准 16000000）
```
