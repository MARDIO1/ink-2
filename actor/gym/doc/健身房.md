# 健身房

`actor/gym/gym.tscn` 是放在关卡里的玩家控制器调参面板。当前实例位于
`map/main.tscn/Gym`，必须排在 `Player` 后面。

## 使用

- 滑块调整“当前基准 × 0.25～5”。
- 右侧数值框直接输入实际参数。
- 质量行显示玩家刚体的实际质量；保存的仍是统一密度倍率。
- 调整只影响当前运行。点击“保存为默认”后，才写入
  `actor/player/asset/player_controller_config.tres`，并把所有滑块的新基准重置为 1。
- 导出版本不能覆盖项目资源，因此保存按钮会禁用。

## 配置范围

配置文件只包含现有 Gym 的 12 个标量：

| 目标 | 参数 |
| --- | --- |
| 脚部 | `max_force`、`max_power`、`move_speed`、`jump_impulse`、`upright_stiffness`、`upright_damping`、`max_upright_torque` |
| 手部 | `max_force`、`max_power`、`position_stiffness`、`position_damping` |
| 身体 | `body_density_scale` |

玩家、脚和手在 `_ready` / 烘焙阶段读取同一份配置。Gym 行仍用场景里的
`target_path` 和 `target_prop` 描述目标，没有另建一套参数表。

## 质量

质量不是独立的 `target_mass`。Gym 统一缩放玩家现有碰撞形状的
`density_scale`，再通过 `PWorld.refresh_mass()` 重算真实质量和转动惯量。
形状与材料编号不变；统一缩放不会移动质心。

质量只在松开滑块或提交数值时重算，避免拖动期间反复扫描像素。
