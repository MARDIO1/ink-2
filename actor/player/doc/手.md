# 手

PD 产生手与身体之间的成对力，限制最大力和主动做功功率。
抓握创建 Weld，松手删除 Weld；负载质量只参与控制计算，不重复添加物理质量。
Hinge 在身体质心允许转动，Slider 允许长度变化并锁定手的相对转角。
`Arm` 是这两个 Joint 之间的内部支座，质量为 4，无重力、无碰撞；不是额外的可操作肢体。
当前引擎没有单个 Joint 同时表达这两个自由度，所以需要这个支座。
`player_physics.gd` 只适配子刚体注册和初始坐标；`hand.tscn` 内部是 `Arm/Hand`，整体挂在 Player 下。

## 成对力与角动量

`hand.gd` 的 `_internal_torques()` 按惯量比给手和身体分配反力矩，`conserve_angular_momentum` 默认关闭。
`player_input.gd` 的 `_apply_pair()` 是脚部的同类结构：反作用冲量给真实支撑体，功率预算里已含转动项。

## 抓握贴图（美术层 + 隐形墨水）

手的物理和画是**两条轨**（通用做法见 `Ink/doc/美术层与隐形墨水.md`）：

- **物理**：`Hand/Shape0` = `player_hand_phys_0.tres`（36x31、354 格），用**隐形墨水**（材质 6）
  烘的同一张剪影；刚体上 `shape_density_scale = 0.1344` 把密度拉回手的 0.1344。质量 47.5776 /
  质心 / 惯量 / 位置与"材质 3 + 无倍率"**逐位相同**（A/B 实测，`test_hand_physics` 三条红项数字逐字一致）。
- **美术**：`Hand/Visual/ArtUnfold`（`player_hand_unfold_0.tres`，36x31）与
  `Hand/Visual/ArtGrab`（`player_hand_grab_0.tres`，35x31），脚本 `Ink/src/pixel_art_layer.gd`，
  只画不物理。左键按下（`_update_grip()` 的 `requested`）切 `visible`，松开切回来 —— 抓空也显示 grab。
- **对齐**：grab 的拳面前缘列（自身 x=34、y=13..18）对准 unfold 的指尖点
  （body 局部 (35.5, 18)，就是 `hand.gd` 的 `FINGERTIP` 常量）→ 节点 `position = Vector2(1, 2)`。
  要挪就改场景里这个 Vector2。
- ⚠️ `Visual.palette` 必须留到 index 6（`[6] = Color(0,0,0,0)`）：物理层在用材质 6 画，缺这一格
  会被夹到最后一格、画成暗灰。
- 验收见 `test_hand_physics.gd` 的 `pose/*` 四条：画出来是哪张图 + 换图不动物理。

## 手臂曲线（只画不物理）

`Arm` 下面挂一条 `Curve`（Line2D + `actor/player/src/arm_curve.gd`）：三次贝塞尔，
起点 = 身体质心（就是 Hinge 的锚点），终点 = 手质心，控制点沿臂方向 1/3、2/3 处各偏一个弓高。

- 弓高 = `min_bow(12) + slack_curve(0.35) × 弦长 × 松弛度`，松弛度 = `1 - 弦长/max_reach` ——
  手伸近时垂成弧，拉满时几乎绷直；法线翻到世界下侧，所以永远往下垂。
- 17 个采样点；`width = 4.0`（= 4px 格稿里 1 格描边，和手/身体的线宽一致）、纯黑、
  圆头 + 圆关节，`z_index = -1` 画在身体和手后面（肩/腕的接头被挡住，不用对位置）。
- `top_level = true`：`points` 直接用世界坐标（`Arm` 节点的节点变换是静态的，不打开就会跟着一个不动的原点）。
- 纯美术：它是 Line2D，没有 `build_shape()`，`collect_shapes()` 看不到它 —— 物理一行没动
  （实测 玩家 2798.33972 / 手 47.5776 / 臂 2.1504 / Rapier 刚体数 5，与加曲线前一致）。
