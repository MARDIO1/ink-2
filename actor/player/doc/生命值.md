# 生命值

`actor/player/src/ink_health.gd`：Player 的子节点 `InkHealth`，玩家「血量」的**单一真源**。
数值就是墨水：0 = 空瓶（液面见底），max_ink = 满瓶。

## 接口

- 查询：`ink` / `max_ink` / `ratio()`（0..1 的液面比例）。
- 增减：`add(amount)` / `reduce(amount)`，自动夹在 0..max_ink。
- `signal changed`：只在数值真的变了时发一次（被夹住也算变）。
- 直写 `ink = x` 不发信号 —— 游戏内不要那么写，走 `add()` / `reduce()`。

## 谁在用它

- `BottledInk`（`actor/player/src/bottled_ink.gd`）：每帧拉 `ratio()` 当液面比例，图层自己不再存 `fill`；
  液面比例 × `capacity_mass` 进合成质量，见 `actor/player/doc/墨水.md`。
- `ui/hud/src/hud.gd`：`health_path` 指过来，`changed` 一响就把横条设成 `ratio() * 100`。
- 预留：碰撞伤害现在只在 `actor/player/src/player_physics.gd` 的
  `apply_collision_damage()` 里累加 `collision_damage`，还没转成 `reduce()`。

## 为什么不放在 BottledInk 里

液面是**表现**，生命值是**数据**：以后质量/质心微调、伤害与拾取都要读它，
而墨水图层可能换成别的表现。所以真源单独一个节点，图层与 HUD 都只是消费者。
