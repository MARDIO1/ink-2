# 墨水

`actor/player/src/bottled_ink.gd`：Player 的子节点 `BottledInk`，瓶里那点液体；液面高度由兄弟节点 `InkHealth` 给（见 `actor/player/doc/生命值.md`）。

液体是 **PBF 粒子流体**（`addons/pixel_destruction/fluid/fluid_pbf.gd`，纯表现，不进物理像素），每帧烘成一张贴图 —— 本节点自己就是那张贴图（`Sprite2D.texture`）：容器内每格要么墨色（有液体）、要么玻璃色（空）。
本节点画在线稿**下面**（`z_index = -1`），所以瓶子看起来是一只带黑线稿的玻璃瓶，只有瓶身里那截是墨色。

- **容器 = 整个瓶身（含不透明的身体块）**，不是"被围住的透明像素"：先四边泛洪出"外面"，取被围住的透明像素里**最大连通分量**的外接框（这一步排除头/瓶盖），框内所有"不是外面"的格子都算容器 —— 得到一个没有洞的实心瓶身。见 `_build_container()`。
- **挡脸**：`_build_render_mask()` 在**原生分辨率（源像素）**上两步走（顺序是契约）：① 从图像四边泛洪**不透明**像素 —— 瓶壁/肩线/瓶盖连得到，**脸的眼睛和嘴连不到**；② 从紧挨着①的透明像素泛洪，得到可出墨水的区域 —— 线稿围起来的空腔（眼睛内部）没有种子，永远走不到。`face_rect` 是手动后备，默认空矩形 = 关。
- **不进物理像素**：本节点不是形状节点（没有 `build_shape()` / `get_shape()`），`PixelBody2D.collect_shapes()` 与 `PixelSprite2D._collect()` 都看不到它 —— 玩家的碰撞形状、像素数、连通性、破坏行为完全不受墨水量影响。
- **不自己烘图**：每帧抄兄弟 `Visual`（`pbody_visual.gd`）的贴图 / offset / 变换，剪影只有一个真源。
- **液面永远世界水平**：重力方向取自像素世界（`_local_gravity()`），液面是粒子流体的自由面；玩家翻了 / 躺下 / 倒立，液面都不跟着翻。
- **虚空质量**：墨水的质量走**已有的合成质量管线**（`shape.density_scale` → `PWorld.refresh_mass()`，按 `mass_quantum` 量化后才重算）。**不要直接写 `PBody.mass`**：每次 rebuild 都会被覆写，而且 Rapier 侧的质量来自碰撞体密度，两边会静默分叉。
  ⚠️ `player.tscn` 没设 `capacity_mass`（默认 0）→ 这条管线目前**空转**，墨水不改变质量。要开就把 `BottledInk.capacity_mass` 填成想要的值（`test_ink.gd` 自己设 1200 来验这条线）。
  ⚠️ `refresh_mass()` 必须带密度回调 `Callable(pw, "_density_of")`：不传就走引擎的 `density_of_material()`，那里把密度 0 兜底成 1.0，白标签那 1310 格会凭空多出 1310 的质量。

液面比例不是本图层的自有属性：每帧读兄弟节点 `InkHealth`（`actor/player/src/ink_health.gd`）的 `ratio()`，
本液体图层不再存 `fill`。谁在改墨水量见 `actor/player/doc/生命值.md`。
