# 墨水

`actor/player/src/bottled_ink.gd` 与同目录 `bottled_ink.gdshader`：Player 的子节点 `BottledInk`，瓶里那点液体。
图层就是一个盖住玩家的方形图，靠 shader 裁成「玩家区域内 + 液面以下」。

- **不进物理像素**：它不是形状节点，没有 `build_shape()`。`player_physics.gd` 的 `collect_shapes()` 和 `PixelSprite2D` 的 `_collect()` 都只认直系子节点的形状，所以它不会被算进碰撞像素（玩家仍是 6 形状 / 4378 格）。
- **不自己烘图**：每帧抄兄弟 `Visual`（`pbody_visual.gd`）的 `global_position` / `global_rotation` / `offset` / `texture`，剪影只有一个真源，重新烘培不用改两处。
- **遮罩**：shader 里 `texture(TEXTURE, UV).a <= 0.0` 就 `discard`，方形图超出剪影的部分自然被剪掉。
- **液面永远世界水平**：`down_local` 是世界重力方向转到节点局部，`level` 由剪影四角沿 `down` 的投影范围与 `fill` 算出；液面以上的像素 `discard`。瓶子翻了液面也不会跟着翻。
- **虚空质量**：墨水的质量直接加到碰撞体上（`fill * capacity_mass`），旋钮是 `shape.density_scale` + `PWorld.refresh_mass()`，按 `mass_quantum` 量化后才重算。**不要直接写 `PBody.mass`**：每次 rebuild 都会被覆写，而且 Rapier 侧的质量来自碰撞体密度，两边会静默分叉。
- **液面晃动用 shader 表达**（未做）：顶点/UV 扰动，不进物理。抖动是水面的视觉，质量只认当前液面。

`fill` 目前是 `@export`，还没有游戏内的产出口（倒墨、消耗墨水）。
