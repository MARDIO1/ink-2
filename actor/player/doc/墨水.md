# 墨水

`actor/player/src/bottled_ink.gd`：Player 的子节点 `BottledInk`，瓶里那点液体；液面高度由兄弟节点 `InkHealth` 给（见 `actor/player/doc/生命值.md`）。
实现是**瓶内遮罩 + 专用液位 shader**：`BottledInk` 的贴图是一张「瓶内遮罩」（alpha 1 = 瓶内），`player_liquid_wobble.gdshader` 直接按 `InkHealth.ratio()` 裁出液面以下部分。旧 `Liquid` 子节点只为场景兼容而保留，运行时隐藏，不再参与裁剪。
所以瓶子看起来是一只有黑线稿的玻璃瓶，只有瓶身里那截是墨色，液面以上是空的。

- **不进物理像素**：`BottledInk` 与 `Liquid` 都不是形状节点，没有 `build_shape()`。`player_physics.gd` 的 `collect_shapes()` 和 `PixelSprite2D` 的 `_collect()` 都只认直系子节点的形状，所以它们不会被算进碰撞像素（玩家仍是 2 形状 / 3304 格）。
- **不自己烘图**：每帧抄兄弟 `Visual`（`pbody_visual.gd`）的 `global_position` / `global_rotation` / `offset` / `texture`，剪影只有一个真源，重新烘培不用改两处。
- **只填瓶内**：`bottled_ink.gd` 从剪影贴图的**空像素**出发做一次四边界泛洪，泛洪到不了的那些封闭空腔就是瓶内，烘成 `FORMAT_RGBA8` 遮罩。shader 只在遮罩 alpha 内画像素；描边（不透明）、瓶盖外的空白、剪影外都不在遮罩里，所以角色永远是黑线稿，墨水只出现在瓶身内部。
  ⚠️ 遮罩只在剪影真的变了时重算：缓存键带 `Visual` 的 `_sig`（含每个 shape 的 `revision`），所以挖洞 / 掉像素会换键重算，每帧只比一个字符串。
- **液面永远世界水平**：脚本把世界重力方向转成角色局部方向，shader 用它投影实际瓶内空腔，再按 `InkHealth.ratio()` 求液面；瓶盖、角色外框和透明留白不计入容量。玩家翻了 / 躺下 / 倒立时液面仍不跟着翻。
- **虚空质量**：墨水的质量直接加到碰撞体上（`ratio * capacity_mass`），旋钮是 `shape.density_scale` + `PWorld.refresh_mass()`，按 `mass_quantum` 量化后才重算。**不要直接写 `PBody.mass`**：每次 rebuild 都会被覆写，而且 Rapier 侧的质量来自碰撞体密度，两边会静默分叉。
  ⚠️ `player.tscn` 没设 `capacity_mass`（默认 0）→ 这条管线目前**空转**，墨水不改变质量。要开就把 `BottledInk.capacity_mass` 填成想要的值（`test_ink.gd` 自己设 1200 来验这条线）。
  ⚠️ `refresh_mass()` 必须带密度回调 `Callable(pw, "_density_of")`：不传就走引擎的 `density_of_material()`，那里把密度 0 兜底成 1.0，白标签那 1310 格会凭空多出 1310 的质量。
- **呼吸与手绘抖动**：瓶身 `Visual` 与墨水专用 shader 使用相同的呼吸、整像素位移和 UV 波动参数；只改变画面，不改变碰撞。质量只认当前液面比例。

只做过一版的坑：曾经在 `fragment()` 里用 `VERTEX` 和局部 `level` 混算，两个坐标系不一致，导致满 / 半 / 四分之一画出来一样。当前版本只用 `UV * texture_size` 的贴图像素坐标，并由脚本传入同坐标系的投影上下界，因此中间液位也能正确渲染。

液面比例不是本图层的自有属性：每帧读兄弟节点 `InkHealth`（`actor/player/src/ink_health.gd`）的 `ratio()`，同时监听它的 `changed` 信号。画布扣墨时 shader 参数与 HUD 同一时刻更新；暂停状态也保持同步。谁在改墨水量见 `actor/player/doc/生命值.md`。
