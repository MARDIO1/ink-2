# 复活点

死亡复活使用最后一次有效激活的点，不在死亡时计算几何最近距离。初次进入关卡时出生点是默认回退；折返重新进入旧点可以切回它。删除当前点后按激活历史回退，再回到出生点。历史只保留在本关玩家实例中，不跨关卡继承。

## 激活

- 使用 PlayerInput 在真实物理步结算的脚底支撑接触点；支撑必须仍在当前 PixelWorld 中。
- 默认范围为 120×32 像素的扁矩形。只有落地接触进入区域才激活，空中经过、编辑器移动、死亡期间和安全恢复期间均不激活。
- 持续站在区域内不重复触发。离开后再次落地进入可重新激活；区域重叠时只在新进入区域的那一帧切换，不在重叠区内来回选最近者。
- 激活时显示约 1.8 秒“复活点已激活”，并发出 `FallDeath.checkpoint_activated(point)` 信号。

旧 Marker2D 地图无需迁移即可使用默认范围。新节点使用 `map/src/respawn_point.gd`，分组、命名前缀和旧 PlayerSpawn2 等标记的兼容规则保持。

## 出生位置与激活区域

标记原点仍是玩家身体的出生原点。激活区默认对齐该出生姿势的碰撞脚底，不把旧标记直接当作地面坐标。触发与编辑器边框共用同一套坐标换算，支持关卡平移、旋转及复活点朝向。

进入地图编辑器，用操纵工具选中橙色复活点，点击“复活点激活区域”，设置：

- 宽度、高度：脚底接触需要进入的矩形尺寸。
- 水平、垂直偏移：相对默认脚底区域的位移，垂直负值向上。

橙色十字是出生位置，扁矩形是激活范围，连线表示两者关系。调整范围不会移动出生标记。区域修改、放置、移动、删除及恢复支持撤销/重做，配置随地图保存。已有无脚本标记在编辑器收集时附加配置脚本。

ESC“脱离卡死”优先使用最后激活点，只在安全搜索无法落脚时回退到更早的点，继续保留碰撞检查和分帧搜索。查询目标或打开菜单本身不会激活新点。

## 验证

- `test_checkpoint_visits.gd`：范围边界、空中经过、相邻楼层、最后激活优先、折返、只读查询、编辑/死亡状态、独立偏移、变换坐标、序列化、删除回退、旧标记、重叠区域。
- `test_checkpoint_floors_live.gd`：在真实上下两层物理平台落地，验证上下层分别激活、靠近旧层不切换、死亡返回上层和折返重新激活下层。
- `test_editor_layout_tools.gd`：区域设置不移动出生位置，撤销/重做、删除恢复、放置重做保留参数与朝向。
- `test_spawn_respawn_canvas_layout.gd`、`test_escape_stuck.gd`、`test_safe_spawn_search.gd`、`test_character_death.gd`：兼容原有布局、脱困和死亡功能。
