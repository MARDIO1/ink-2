# 蓝图模块架构

本文件是蓝图的边界契约与迁移计划。改蓝图之前先读它；玩法细节见
[`ui/hud/blueprint/doc/blueprints.md`](../../../../ui/hud/blueprint/doc/blueprints.md)。

## 现状（2026-10-18 实测）

| 文件 | 行数 | 现在负责什么 |
| --- | --- | --- |
| `actor/canvas/blueprint/src/blueprint_codec.gd` | 623 | 采集、缩略图、耗墨、碰撞检查、放置事务 |
| `ui/hud/blueprint/src/blueprint_store.gd` | 352 | JSON v1 格式、校验、读写、迁移、文件名 |
| `ui/hud/blueprint/src/blueprint_system.gd` | 707 | 手册、搜索、详情、重命名、放置预览、切换画布工具 |

**反向依赖（必须打断）**：

```gdscript
# blueprint_codec.gd:5
const Store := preload("res://ui/hud/blueprint/src/blueprint_store.gd")
```

Codec 只用到 `Store.VERSION`、`Store.MAX_SIDE`、`Store.validate()`
（:38、:41、:268、:508）。也就是说**数据格式被锁在 UI 目录里**，
非 UI 的模块想读蓝图必须先拉进整个 HUD 层。

## 目标：三段式

```
blueprint/                     ← 核心：无 UI、无地图实体依赖
├─ src/
│  ├─ blueprint_format.gd      版本、上限、validate（当前在 store 里的那部分）
│  ├─ blueprint_store.gd       文件读写、迁移、命名
│  ├─ blueprint_codec.gd       选区采集、缩略图、耗墨、放置事务
│  └─ blueprint_place.gd       放置检查与提交（纯函数 + 回调）
└─ doc/架构.md

actor/canvas/blueprint/        ← 画布表现：选旁按钮、幽灵预览、范围显示
ui/hud/blueprint/              ← 屏幕界面：库、搜索、详情、重命名、删除
```

### 依赖方向（单向，可自动检查）

```
ui/hud/blueprint  ──►  actor/canvas/blueprint  ──►  blueprint/src
        │                                              ▲
        └──────────────────────────────────────────────┘
```

规则：**`blueprint/src` 不得 preload 任何 `ui/` 或 `actor/` 路径**；
`actor/canvas/blueprint` 不得 preload `ui/`。违反即视为架构回归。

## 五条必须保证的行为

1. **保存连接关系**，不只是像素和世界坐标：轴承、导轨、滑块、弹簧、动力箭头的
   配对信息随蓝图走。
2. **重复放置重建独立连接**：新装置的所有刚体/关节都是新建的，不引用原装置对象
   （尤其不能共享 `PBody` 或 `joint`）。
3. **放置前完成检查**：范围、碰撞、各色墨水费用逐项预检；失败**不生成半套装置、
   不扣墨水**。
4. **一次放置 = 一次撤销**：撤销同时恢复像素、部件、连接与墨水数量。
5. **编辑与游玩共用同一套放置实现**，只通过参数区分使用距离与费用规则
   （当前是 `editor_only` + 距离检查的分支，应收敛成入参）。

## 迁移步骤

| 步 | 做什么 | 门禁 |
| --- | --- | --- |
| B1 | 把 `VERSION` / `MAX_SIDE` / `validate` 从 store 抽到 `blueprint_format.gd`，store 与 codec 都改成引用它 | `test_blueprints`、`test_blueprint_ui` |
| B2 | `blueprint_store.gd` 搬到 `blueprint/src/`，HUD 侧改为引用新路径 | 同上 + 文件名/重命名测试 |
| B3 | 放置事务从 codec 里拆出 `blueprint_place.gd`（检查、提交、撤销一步到位） | 放置/撤销/重做一致 |
| B4 | `blueprint_system.gd` 只保留界面与"请求放置"；不再直接建刚体、扣墨水 | UI 测试 |
| B5 | 补连接保存/恢复的断言（含齿轮轴承与导轨滑块） | 新增断言 |

## 不做的事

- 不把蓝图格式并进地图存档：两者共用**采集/恢复函数**即可，格式保持独立。
- 不引入第二个"文档引擎"；继续用 Godot 场景 + Resource。
- 不在迁移过程中改变 `.inkbp` 的对外格式；B1/B2 是纯搬家。
