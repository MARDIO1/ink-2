# 画布

画布在编辑器 2D 舞台可见，选中 Canvas 修改 `canvas_size`。
Area2D 的 Bounds 随尺寸更新，只显示范围，不参与像素刚体碰撞。

## 结构

`Canvas` 是控制器：工具状态、按钮、公开接口。
`CanvasSurface` 是画面：像素缓冲、鼠标绘制/擦除。
`CanvasSolid` 是实体化：正向固化与反向栅格化。

## 工具

`CanvasSurface.tool` 七选一，**只有左键**，行为完全由工具决定（右键已砍掉）：

| 工具 | 键 | 左键 |
|---|---|---|
| 普通手 | `1` | 不响应 |
| 画笔 | `2` | 按笔刷落黑墨 |
| 墨水桶 | `7` | 灌满点所在的封闭空区 |
| 矩形 | `5` | 拖拽画外框 |
| 圆形 | `6` | 拖拽画外框 |
| 橡皮擦 | `3` | 按笔刷擦除 |
| 钉子 | `4` | 落一个材质 4 的钉子像素 |

中键保留：在鼠标处放一枚钉子。工具只作用于画布自身，不门控玩家手臂。

左下角工具面板是 `WorkbenchUI`（**Node2D，世界物件，跟着画布走；不是 CanvasLayer**）→
`Buttons`（Control）→ `Grid`（GridContainer），9 个按钮：
`Brush / Eraser / Shape / Nail / Bucket / ReturnToCanvas / Generate / Redraw / Hand`
（按钮自带 tooltip 写键位）。全部 `focus_mode = 0`：工具按钮不进键盘焦点链，否则点过之后
Tab 会被 GUI 当 `ui_focus_next` 吃掉（见 `ui/hud/doc/HUD.md`）。

`Hand`（普通手，热键 `1`）没有图标素材，先用文字「手」；它有 `toggle_mode` 且和其余工具按钮
共用一个 `ButtonGroup`，`_apply_tool()` 会同步它的按下状态（用热键切工具时高亮也跟着走）。

面板按玩家距离显隐（`toolbar_show_distance` / `toolbar_hide_distance`），笔触粗细在
`WorkbenchUI/BrushPanel` 的 `PenSlider`。

地图编辑模式调用 `set_map_editor_mode(true)` 后，工具栏通过逆视口变换固定在屏幕左侧，
不受相机平移、旋转和缩放影响；普通手按钮隐藏，并显示四向扩大、小人显隐和钉子显隐开关。
钉子开关同时控制 `NailLayer` 与 `nail_visual` 组，仅切外观，不修改材质 4 像素或锚点标签；
隐藏期间新生成的钉子也会继承隐藏状态。

图标资源在 `ui/asset/`（8 组 png + AtlasTexture），按钮/面板样式走共享 Theme。

## 矩形 / 圆形

两个都是**拖拽工具**，画的都是**外框**（不填充），线宽 = 右侧笔触滑块的直径：

- **矩形**：按下点是一角，拖到对角。
- **圆形**：按下点是**圆心**，拖出的距离是**半径**，永远是正圆（不做椭圆）。

实现就是"拿笔刷沿边界扫一圈"（`_brush_line` / `_brush_circle` → `_collect_stamp`），
所以"框半径就是笔触半径"自然成立。沿线的脚印步长取 `max(1, 笔刷直径/2)`，
保证圈与圈之间不留缝。

拖拽时**实时预览**：每动一次先把上一帧改过的像素还原（`_shape_saved` 存着原色），
再按新位置重画一圈。**松手才记账**（`_end_shape` 里调一次 `_apply_ink_delta`），
所以拖拽过程不会反复扣墨水；墨水不够时超出部分的格子不落笔。

## 墨水桶

点一下，把**点所在的连通空区**一次灌满（`_bucket_fill`）。三个取舍：

- **必须封口**：一旦漫到画布边缘就说明这片区域是敞开的（点在了开阔处），**直接放弃**。
  否则创造模式免墨水、没有余额上限，一下就把整张图灌满 —— 大地图 2048×1024 = 200 万格，
  既没用又会卡死。这也是最快的退出路径：栈是后进先出，DFS 顺着一个方向几步就撞到边。
  实测点开阔处 **1.7 ms** 退出、一个像素不落。
- **4 邻接，不是 8 邻接**：数字拓扑里"8 连通的边界"正好困住"4 连通的填充"。
  圆形的 1px 外框是斜着走的（8 连通），只有 4 邻接的填充才不会从斜缝里漏出去。
- **要么全灌、要么不动**：先数够不够，瓶里不够就什么都不画（半灌的封闭区看着像坏了）。
  数的时候一旦超过余额就提前退出，不会为了一个灌不下的大区域白扫全图。
- **走原始字节**（`Image.get_data()` → 改 alpha/RGB → `set_data`）：逐像素 `get_pixel`/`set_pixelv`
  在几十万格时不划算。

⚠️ 两个 GDScript 坑都踩过，别再犯：
1. `PackedByteArray` / `PackedInt32Array` **按值传递**，入栈和标记**必须内联**在循环里；
   塞进 helper 改的是副本 —— 会变成永远推同一个像素的死循环。
2. 1px 笔刷**不能走距离判定**：采样点正好落在格角上时（x、y 都是整数）半径 0.5 够不到任何格心，
   会一个像素都不落。闭合轮廓上只要缺一格，桶就灌满全图。现在直径 1 直接取"点所在的那一格"。

## 墨水账

两本账，互相解耦：

- **瓶子**（`Player/InkHealth`）记"还剩多少墨水"，屏幕左上角那个读数读的就是它。
- **画布**（`CanvasSurface.ink_px`）记"这张画布上此刻写着多少个实心像素"。
  它是**每张画布自己的账**，和瓶子无关 —— 以后有多张画布也不会互相串。

`canvas_surface.gd` 的 `health_path`（默认 `../../Player/InkHealth`）只是把画布的
增减传给瓶子；瓶子不参与判断"画布上有多少墨"。

| 动作 | 账 |
|---|---|
| 画笔/钉子画出**原本为空**的像素 | 每个扣 1 px（`reduce`） |
| 重复涂已有墨水的像素 | 不扣（不是新像素） |
| 橡皮擦擦掉**原本有墨**的像素 | 每个还 1 px（`add`） |
| 擦空白处 | 不还 |
| 重绘（`clear(refund = true)`） | 把**这张画布的** `ink_px` 全还回瓶子 |
| 固化（`clear(false)`） | **不还** —— 这些墨水已经变成刚体带走了 |
| 重新回到画布（`write_pixel`） | **不碰瓶子**（固化时已经扣过），但要把 `ink_px` 补上 |

⚠️ `write_pixel` 那条路（`CanvasSolid.rasterize` 用来把刚体重采样回画布）**必须**同步
`ink_px`：它不碰瓶子是对的，但漏掉画布的账就会让这些像素对账本隐形，
之后"重绘"退不回它们 —— 表现就是「抓回来的物品，墨水永远回不来」。

一笔只发一次 `changed`（`_stroke` 累计净变化后调一次 `_apply_ink_delta`），
不会每像素刷一次 HUD。瓶里不够时画不出来：`_stamp` 带 `allowance`，扣完就停。

怀疑账本漂了就调 `recount_ink_px()` 按像素重数一遍（全图扫，只走一次性路径）；
`load_ink` 读盘后会自己重数。

HUD 左上角只显示瓶子**还剩**多少（`InkHealth.ink`），不显示"已消耗"——
那是瓶子级的全局量，放进屏幕会和"多张画布"这件事打架。

### 免墨水模式

`CanvasSurface.ink_free = true` 时整张画布**不和瓶子对账**：画、擦、重绘都不动墨水，
`ink_px` 也保持 0。打开的那一刻会先把当前 `ink_px` 还回瓶子（把账结清），
免得"之前花钱画的"和"之后免费画的"混在一起。

创造模式（地图编辑）会打开它，见 `debug/creative/doc/创造模式.md`。

## 无损扩大画布

`Canvas.expand_canvas(direction, amount)` 只允许四个轴向方向。底层
`CanvasSurface.resize_preserving_content()` 会建立更大的透明图并搬运旧像素与钉子，
不退款、不重算墨水账。向左或向上扩展时 `Canvas` 节点会反向移动相同距离，保证旧内容的世界坐标不变。

## 钉子

钉子只有**一套**：画布上的一个材质 4 像素。细节见 `actor/nail/doc/钉子.md`。

画布这边只做三件事：

- 落笔：工具 4（数字键 `4` 或中键）写钉色，**只落单像素**，不铺笔刷（`_place_nail`）。
- 编辑时显示：`CanvasSurface/NailLayer` 用 `actor/nail/src/nail_layer.gd` 把钉子像素画成钉子。
- 固化时：`CanvasSolid` 把含钉子像素的连通块设成 `is_static = true`、打 `static_anchor_points`，
  并为每个钉子像素生成一个 `actor/nail/src/nail.gd` 贴在刚体上 —— **画布清空后钉子仍留在刚体上**。

`load_ink` 后按像素颜色重建编辑态的钉子外观层。

## 按钮

`canvas.gd` 的 `_bind_buttons()` 在运行时接线（节点见上节 `WorkbenchUI/Buttons/Grid`）：

| 按钮 | 调用 |
|---|---|
| 画笔 / 橡皮擦 / 形状 / 钉子 / 墨水桶 | `set_tool(...)` |
| 重绘 | `clear_canvas()` |
| 生成 | `generate()` |
| 重新回到画布 | `return_to_canvas()` |

## 公开接口

`canvas.gd` 暴露 `clear_canvas()`、`generate()`、`return_to_canvas()`、`set_tool(tool)`、
`expand_canvas(direction, amount)`、`set_map_editor_mode(on)`，
按钮、键位、外部脚本都走这几个口。

## 固化

`canvas_solid.gd` 把表面墨水按 4 邻接连通分量拆成多个刚体，用的是引擎的 `Destruction.split(shape, 1)`。
含钉子的连通块成为静态体；固化成功后清空画布上的蓝图墨水。

## 反向：实体重采样回画布

`canvas_solid.rasterize(surface, world)` 扫画布范围内所有刚体（**只认 `PixelBody2D` 节点**），
按材质颜色（`black`→黑墨水）临近采样写回画布，并把刚体从世界移除。
带 `living` 标签（玩家、手、NPC）的刚体跳过；玩家与手在 `player_physics.gd` 的 `bake()` 里打标签。
像素总量近似守恒，重叠处会合并。

⚠️ **钉子不回收**：材质 4 不回画布，挂在上面的 `Nail` 外观一并丢掉。
原因有两个：`Nail`（Sprite2D）自带 `body` 属性，按"有没有 body"认刚体会把它当刚体收走，
`remove_body_node` 参数类型不符，直接报错/崩溃；而且钉子本来就钉在刚体上，回画布没意义。

## 热键

都在 `actor/canvas/src/canvas.gd` 的 `_input`（`:70`），编辑器里不生效。

- `E`（裸键码，不走动作）：`generate()` 固化（与“生成”按钮等价）。
- `F5`（动作 `canvas_save`）：`save_ink(capture_path)`，并另存 `save_png(baked_map_path)`。
- `F9`（动作 `canvas_load`）：`load_ink(capture_path)`。

`capture_path` 默认 `res://test/canvas_capture.tres`（`:27`，开发复现文件，当前磁盘上不存在，第一次 F5 才生成）；
`baked_map_path` 默认 `res://map/asset/baked_map.png`（`:29`）。
