# 画布邻近交互

游玩画布复用现有接近/离开距离滞回（190/214 像素），防止边缘抖动。
左侧工具、隐藏按钮和右侧色盘在离开时用 0.22 秒淡出，尺寸仅轻微缩至 96%，随后隐藏；回到画布反向淡入。
淡出期间立即禁用点击；快速进出会取消旧动画，避免过期回调把新展开的工具栏隐藏。
手动隐藏工具栏的选择保持不变。

邻近画布只显示一套两侧工具栏，指向画布时接棒；当前工具、颜色与笔触大小随交接保留。绘制、框选拖动或点击工具栏时锁定归属。
工具栏场景位于 `actor/canvas/toolbar/toolbar.tscn`，负责**右侧墨水面板**：保持屏幕尺寸、无底板或外框（左侧工具阵列另有纸色底板，见 `画布.md`）。间隔不超过 96 像素的画布按相连整体定位两侧工具栏，切换归属不会改变它们的位置。视野内直接贴合画布两侧，不对整体位置做缓动；仅横向越界时调整到屏幕左右边缘，高度始终跟随画布，不做上下避让。地图编辑模式保留独立工具栏。

玩家离开所有邻近游玩画布后，工具自动切回 HAND，结束当前笔画/选区，恢复玩家手部。
移入相邻的另一画布时不会强行中断那里的绘制；地图编辑模式不执行离开自动切手。

相机靠近画布平滑放大至基准缩放的 1.15 倍，离开后平滑恢复；不改变画布像素大小。
基准来自当前体素倍率和视口比例，不累乘缩放。地图编辑模式不应用邻近放大。
参数可在 Canvas 的 `toolbar_transition_seconds` 和 Camera 的 `canvas_zoom_multiplier` / `canvas_zoom_response` 调整。
