# 美术层与隐形墨水

**物理贴图 ≠ 美术贴图**时的通用做法。默认仍然是"像素物理"：碰撞、破坏、质量、惯量全都派生自
刚体的像素形状；美术层只是**多画一张**，谁都不许改物理。两个子系统：

| | 谁 | 在哪 | 管什么 |
| --- | --- | --- | --- |
| 物理 | `PixelShape2D`（引擎的形状节点） | 刚体的**直接子节点** | 碰撞、质量、质心、惯量、破坏 |
| 美术 | `Ink/src/pixel_art_layer.gd`（Sprite2D） | 刚体的渲染节点 `Visual` **下面** | 只画。位姿自动跟着刚体走 |

`PixelWorld` 只看刚体的直接子形状（`PixelBody2D.collect_shapes()`），所以挂在 `Visual` 下的美术层
**永远进不了物理** —— 挪错位置也进不去（它不是形状节点，没有 `build_shape()`）。

## 美术层 `pixel_art_layer.gd`

- `image`：R 通道 = **材质 id**（和 `tools/bake_art.gd` 的产物同格式，`Image` 资源直接拖进来）。
- `palette`：材质 id → 颜色。**留空就用像素世界的调色板**（`PixelWorld.palette_for_render()`，和物理层同源）。
- 多层：想叠几层就挂几个，各自 `visible`。动作/动画无非是切 `visible` 或换 `image`。
- 每次重建都**新建 `ImageTexture`**，不调 `update()` —— 换图时尺寸可以随便和物理形状不一样。

## 隐形墨水（材质 6）

`Ink/asset/invisible.tres`：`color = (0,0,0,0)`（画不出来）、`density = 1.0`（基准密度）、
在 `map/main.tscn` 的 `materials` / `densities_fallback` 里登记为 **id 6**。

用它当**物理剪影**：碰撞/质量照旧，屏幕上什么都不画，画交给美术层。

- 密度靠 `shape_density_scale` 拉回（`actor/player/src/player_physics.gd` 的导出，按刚体在场景里设）。
  手 = `0.1344`：质量 `354 格 × 1.0 × 0.1344 = 47.5776`，与原来"材质 3 密度 0.1344"**逐位相同**；
  质心 / 惯量同（统一倍率不移动质心）。
- **实测零影响**：把手的物理剪影在"材质 3"与"材质 6 + density_scale"之间切换，`test_hand_physics`
  的三条红项数字逐字一致（`-13.105 / -14.265 / 3.693117`）。
- 碎片保留隐形：材质跟着像素走，破坏出来的碎片照样是隐形的（换成"在 palette 里改透明"就做不到）。

⚠️ **palette 下标 = 材质 id**：显式写了 `palette` 的节点必须把数组补到 index 6（`[6] = Color(0,0,0,0)`），
否则渲染端会把 `6` 夹到最后一格，画成别的颜色。留空走世界调色板则天然正确。

## 边界（必须知道）

- **美术层不受物理裁剪**：打洞、断裂、掉像素只发生在物理那层，美术层不会跟着变。要跟着破，
  照 `actor/player/src/bottled_ink.gd` 那套：把物理贴图当 alpha 遮罩 + `clip_children = 仅裁剪` 裁一遍。
- 因此：**会被打坏的东西，物理那层不要隐身**（玩家的物理层保持可见，美术层只做叠加）；只有
  "外观完全由美术层负责"的东西（手、武器、纯动作姿态）才用隐形墨水。
- `ImageTexture.update()` 的限制（实测，Godot 4.7.2）：新图必须和已创建的纹理**宽高逐格相同、格式也相同**，
  差 1 格就报 `The new image dimensions must match the texture size.` 并**静默留旧图**。
  美术层因为每次新建纹理，不受这条限制；`PixelSprite2D`（画物理形状那个）会受影响。

## 加一个新美术贴图的步骤

1. `tools/bake_art.gd` 的 `SOURCES` 加一行（材质给 3 这类**看得见**的 id）；跑 `bake_cli.gd`。
2. 目标刚体的 `Visual` 下挂一个 Sprite2D，脚本选 `Ink/src/pixel_art_layer.gd`，`image` 指向刚烘的 `.tres`。
3. 要"物理隐身"就把刚体子形状的 `paint` 换成隐形墨水版本（材质 6），并在刚体节点上设 `shape_density_scale`
   把质量拉回原值；`Visual.palette` 补到 index 6 = 透明。
4. 验收钉住两条：换图前后 `mass / inertia / local_com / position` 与 Rapier 侧刚体数不变；画出来的是期望那张图。
   样例见 `test/test_hand_physics.gd` 的 `pose/*`。
