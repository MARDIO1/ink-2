# 创造模式（地图编辑模式）

F2 进出。进去后就是地图编辑器：飞行、画、放钉子、固化、存图。

## 操作

| 键 | 作用 |
|---|---|
| `F2` | 进出创造模式 |
| `WASD` | 上帝位移（直接改位置，不走惯性），`Shift` 加速 |
| `1` / `2` / `3` / `4` | 手 / 画笔 / 橡皮擦 / 钉子 |
| `F5` | 固化画布 → 把墨水物品导出成地图场景 |
| `Esc` | 照常开菜单 |

## 进入时改了什么

- 玩家本体 `collision_layer = 0`、`collision_mask = 0`：不在任何层，碰不到任何东西，也碰不到它。
- 玩家本体 `gravity_scale = 0`：不下落。
- `WASD` 每帧直接**设速度**（起步/停止都是瞬时的，没有惯性手感）。手/臂不受影响，抓握照常。
- 退出时把层、掩码、重力恢复；**位置不还原**（停在你飞到的那个点）。
- 小画布 `Canvas` 让位：`visible = false`、`active = false`；
  大地图 `MapCanvas`（2048×1024，铺满全图）出现并接管输入。退出时换回来。

`process_physics_priority = 15`：在世界步进(10)之后、相机(20)之前改位置，这样相机当帧就跟上。

### 为什么是"设速度"而不是瞬移位置

第一版每帧直接写 `body.position`。本体是手臂两根关节（Hinge + Slider）的锚点，
瞬移等于把锚点一下子拉开，求解器为了追上会把质量只有 2.15 的手臂抽到 **39361 px/s**，
实测 **331 个子步/帧、1074 ms/帧**（`debug_hud` 的看门狗直接抓到现场并退出）。

改成设速度后位移交给物理积分，关节锚点连续，飞行时最大 6 子步、124 FPS（静止 166 FPS）。

## 存图

`F5` → `Creative.export_map()`：

1. `Canvas.generate()` 先把画布上没固化的墨水固化掉，一个像素都不丢。
2. `map/src/map_export.gd` 扫描 `ink_item` 组里的每个墨水物品，打包成
   `res://map/asset/map.tscn`：每个物品一个 `InkItem`（`PixelBody2D`）
   + 若干 `PixelShape2D(source=PAINT)`，材质图内嵌在场景里。

固定路径、每次覆盖，所以地图永远只有一个文件，`main.tscn` 里 instance 它即可。

## 载入

`map/src/ink_item.gd` 是地图场景里每个物品的脚本（引擎 `PixelBody2D` 的子类）。
它在烘焙时按自己的像素补两件事：材质 4 的像素重新打上 `static_anchor_points` 标签，
并补上可见的钉子外观。所以存过再读，钉子还是钉子，静态还是静态。
