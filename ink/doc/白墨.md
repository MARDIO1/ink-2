# 白墨 V1

白墨使用已有 InkItem / PixelBody2D / PBody。材质 id 为 10，碰撞 layer 和 mask 均为 0；初速度沿用节点配置，受世界重力、终端速度和速度上限影响。没有摩擦、碰撞冲量或空气阻尼；外部冲量在下一固定步恢复，爆炸和抓取的普通查询不会选中白墨。

白墨独立固化，允许与世界中的实体重叠。分离的白色笔迹共用一个刚体。面积减小时只清 PixelShape 的块并标脏，不重建质量、质心或原生碰撞体，也不做连通性分片。消耗完或离出生位置超过 4096 px 时释放载体。

## 擦除

每个固定步记录白墨和目标位姿。白墨占用块合并成 16×16px 粗刷子，复用 `Destruction.Damage.segment()` 生成旧/新位置间的线段扫掠区域。普通实体按扫掠包围区覆盖 8×8px 目标块，合并后提交一次；保留材质过滤，钉子不删。没有自写凸包、扫描线或碰撞 TOI 算法。沿用 SimulationRuntime 的 removal / fracture / sync，分片时复用整块未变化的质量缓存；渲染同步只提交变化体。

- 黑墨、灰墨、红墨可删除；红墨按已有规则触发下一步爆炸。
- 钉子、普通怪物、手和手臂暂不处理。
- 黄色有效笔画被覆盖后立即移除约束，整根播放死亡动画和释放音，不退款；动画结束后释放节点。
- 玩家通过 `apply_corrosion_damage(amount)` 扣黑墨生命，保留形状，遵守 `damage_enabled`。
- 激活白墨与腐蚀结果不能撤销。发生腐蚀时清理旧画布撤销事务，防止复活被删的实体和黄线。

白墨消耗 = 本轮直接擦除像素数 / 效率。效率默认 `clamp(1 + speed / 300, 1, 4)`，余数跨步累积。黄线销毁按一次事件计数；红墨额外引爆的区域不额外收费。本轮扫掠完整执行后减白墨面积，耗尽时允许最后一轮超额擦除，不做精确的中途停止位置或两两配对。

白墨自身采用固定块序磨损，速度和面积不相互反馈。粗刷子会提前接触、扩大边缘、填平小于网格的缺口；不是整个白墨包围盒，大空洞仍保留。高速斜移会多擦线段包围区的角落，误差随位移增大；快速旋转目标仍只有旧/新位姿近似，不是完整旋转 CCD。黄色按线段本身命中判断。玩家保留原形状，仅扣血。

## 文件结构

主规则只有 `ink/src/white_ink.gd` 一个文件，材质为 `ink/asset/white.tres`。没有独立载体类或第二套伤害系统。黄色死亡接口留在黄色管理器，玩家扣血接口留在 player_physics。

引擎 GDScript 增加兼容旧调用的三个小入口：碎屑清理排除列表、初始阻尼 tag 覆盖、节点烘焙时允许保持非连通形状；消融热路径复用原生连通标注、按块删除、提前结束最小面积判断，质量缓存命中时不重复计数。没有修改原生 DLL。重新生成 addon 时需要保留这些改动。
